# Adopt Inertia.js with SSR for Frontend-Backend Integration: Custom Middleware Extending

## Status
Proposed

## Context
Inertia.js provides a bridge between Laravel backend and Vue/React frontend without requiring a separate API layer. Server-Side Rendering (SSR) capability enhances initial page load performance and SEO. Custom middleware extending Inertia's base middleware is necessary to implement application-specific request handling, authentication checks, and data sharing patterns.

## Decision
We adopt Inertia.js with SSR enabled for frontend-backend integration, establishing a standardized approach for custom middleware that extends Inertia's base middleware functionality.

## Policies

1. Custom middleware extending Inertia's base middleware MUST be placed in app/Http/Middleware/ and follow the naming convention Ensure[Feature][Condition].php

## Rationale
- Inertia.js eliminates the need for a separate REST/GraphQL API while maintaining clean separation of concerns
- SSR improves Time to First Contentful Paint (FCP) and provides better SEO
- Standardized middleware naming and location ensures discoverability and maintainability
- The Ensure[Feature][Condition] naming convention clearly communicates middleware intent (e.g., EnsureUserIsAuthenticated, EnsureTeamHasAccess)
- Centralizing custom middleware in app/Http/Middleware/ maintains Laravel conventions

## Consequences
- **Positive**: Faster initial page loads with SSR; reduced API complexity; clearer middleware responsibilities
- **Negative**: Additional server-side rendering overhead; potential increased memory usage during SSR; middleware must be carefully designed to avoid blocking operations
- **Mitigation**: Implement caching strategies for SSR; monitor server performance; use async operations where possible

## Implementation Notes
- Custom middleware should extend HandleInertiaRequests or implement MiddlewareContract
- Middleware should be registered in app/Http/Kernel.php
- Follow Laravel middleware best practices for performance and security
