# Adopt Inertia.js with SSR for Frontend-Backend Integration: Feature Gating Middleware

## Status
Proposed

## Context
When integrating Inertia.js with server-side rendering (SSR) for frontend-backend communication, feature-gating middleware must work seamlessly within Inertia's response cycle. Traditional middleware that performs hard redirects can break the single-page application (SPA) navigation model and create poor user experiences.

## Decision
Adopt Inertia.js with SSR and implement feature-gating middleware that integrates with Inertia's response cycle to provide seamless redirects without breaking SPA navigation.

## Rationale
- Inertia.js provides a bridge between backend and frontend that preserves SPA behavior while allowing server-side rendering
- Feature-gating middleware must respect Inertia's request/response model to maintain navigation continuity
- Seamless redirects prevent jarring page reloads and maintain user context
- SSR enables better SEO and initial page load performance while feature gates protect incomplete features

## Policies

1. Feature-gating middleware (e.g., EnsureSignupIsEnabled) SHOULD integrate with Inertia's response cycle to provide seamless redirects without breaking SPA navigation

## Consequences

### Positive
- Consistent user experience across feature-gated and non-gated features
- Maintains SPA navigation benefits while protecting incomplete features
- Server-side rendering improves performance and SEO
- Middleware logic remains centralized and testable

### Negative
- Requires careful coordination between backend middleware and Inertia response handling
- Team must understand Inertia's request/response cycle to implement correctly
- Additional complexity in middleware stack compared to traditional redirects

## Implementation Notes
- Use Inertia's redirect response type for feature-gate denials
- Ensure middleware executes before route handlers to catch feature-gated requests early
- Test both SPA navigation and direct URL access scenarios
- Document feature-gate patterns for team consistency
