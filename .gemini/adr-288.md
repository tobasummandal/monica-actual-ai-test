# Adopt PHPUnit for Unit Testing in Domain-Driven Architecture: Test Suites Executable

## Status
Accepted

## Context
In a domain-driven architecture, unit tests serve as executable specifications and safety nets for refactoring. PHPUnit is the de facto standard testing framework for PHP applications. For tests to provide continuous value, they must be reliably executable within automated CI/CD pipelines.

## Decision
We adopt PHPUnit as the standard unit testing framework and establish policies ensuring all test suites are executable in CI/CD environments.

## Policies

1. Test suites SHOULD be executable in CI/CD pipelines for automated verification

## Rationale
- PHPUnit provides comprehensive assertion libraries and mocking capabilities suited to domain-driven design
- Executable test suites in CI/CD enable early detection of regressions and integration issues
- Automated verification reduces manual testing burden and improves deployment confidence
- Standard tooling across the team reduces onboarding friction and knowledge silos

## Consequences
- All developers must maintain test suite compatibility with CI/CD environments
- Infrastructure costs may increase due to test execution overhead
- Test execution time becomes a critical performance metric
- Teams gain confidence in automated deployments and rapid iteration cycles
