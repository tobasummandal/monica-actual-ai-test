# Adopt CardDAV/WebDAV Protocol for External Contact Synchronization: Viewhelpers Integrate Dav

## Status
Proposed

## Context
External contact synchronization requires a standardized protocol for interoperability across multiple contact management systems. CardDAV and WebDAV provide industry-standard mechanisms for contact data exchange. ViewHelpers need to integrate DAV synchronization capabilities into user-facing components to enable seamless vault and personalization features.

## Decision
Adopt CardDAV/WebDAV protocol for external contact synchronization with ViewHelpers integration for synchronization status display and user controls.

## Policies

1. ViewHelpers MAY integrate DAV synchronization status and controls into user interface components for vault and personalization features

## Rationale
- CardDAV/WebDAV are mature, standardized protocols with broad ecosystem support
- ViewHelpers provide appropriate abstraction layer for UI integration
- Enables user visibility and control over synchronization processes
- Supports vault security and personalization workflows

## Consequences
- ViewHelpers must implement DAV status rendering and control components
- Requires DAV client library integration
- Enables cross-platform contact synchronization
- Increases UI complexity for synchronization management

## Alternatives Considered
- Proprietary synchronization protocol: Less interoperable
- Direct API integration: Tighter coupling, less standardized
