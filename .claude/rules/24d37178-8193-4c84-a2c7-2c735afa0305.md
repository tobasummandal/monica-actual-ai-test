These rules are ALWAYS ACTIVE for all frontend-backend integration patterns in the application.
</rule_activation>

### Rules

- **R-INERTIA-001** MUST: Custom middleware extending Inertia's base middleware MUST be placed in `app/Http/Middleware/` and follow the naming convention `Ensure[Feature][Condition].php`
- **R-INERTIA-002** MUST: All new Laravel controllers returning frontend responses MUST use `Inertia::render()` instead of traditional `view()` or JSON responses for frontend-facing routes
- **R-INERTIA-003** MUST: Configure SSR server with appropriate memory limits and process management (PM2 or similar) to handle rendering load and automatic recovery from crashes
- **R-INERTIA-004** MUST: When creating custom middleware that affects Inertia requests, extend the `HandleInertiaRequests` base class or carefully test integration with Inertia's middleware stack
- **R-INERTIA-005** SHOULD: Organize JavaScript components in `resources/js/Pages/` directory following Inertia conventions, with each component corresponding to a controller action
- **R-INERTIA-006** SHOULD: Use Inertia's shared data mechanism for global props (user, flash messages, etc.) rather than passing them individually to each page component

### Verify

```bash
# Verify Inertia::render() usage in controllers
grep -r "Inertia::render" app/Http/Controllers/ | wc -l

# Verify both entry points exist
test -f resources/js/app.js && test -f resources/js/ssr.js && echo 'Entry points exist'

# Verify custom middleware naming convention
find app/Http/Middleware -name 'Ensure*.php' -type f | xargs grep -l 'Middleware'

# Verify Inertia.js dependencies in package.json
grep -r "@inertiajs" package.json
```

**Accept when:**
- All frontend-facing controller actions use `Inertia::render()` for responses, verified by grep showing multiple occurrences in controllers
- Both `app.js` and `ssr.js` entry points exist in `resources/js/` directory
- Custom middleware files following `Ensure[Feature][Condition].php` naming pattern exist in `app/Http/Middleware/`
- `package.json` contains `@inertiajs` dependencies indicating proper installation
