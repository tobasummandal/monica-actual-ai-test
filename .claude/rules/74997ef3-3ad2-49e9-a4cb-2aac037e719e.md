<rule_activation id="74997ef3-3ad2-49e9-a4cb-2aac037e719e" title="Standardize Eloquent Models as Primary Data Access Layer with Public API Contracts: Models Define Fillable" applies_to="app/Models/**/*.php">
These rules are ALWAYS ACTIVE for all Eloquent model files within the application codebase.
</rule_activation>

### Rules

- **R-ELOQUENT-001** SHOULD: Models SHOULD define `$fillable` or `$guarded` properties to control mass assignment protection.

### Verify

```bash
# Count all model classes extending Eloquent Model
grep -r "class.*extends.*Model" app/Models/ | wc -l

# Check for syntax errors in all model files
find app/Models -name '*.php' -exec php -l {} \; | grep -v 'No syntax errors'

# Count raw database queries outside models (should be minimal)
grep -r "DB::raw\|DB::select\|DB::statement" app/ --exclude-dir=Models | wc -l
```

**Accept when:**
- All model classes in `app/Models` extend `Illuminate\Database\Eloquent\Model`
- No syntax errors in model files and all models are loadable by PHP parser
- Raw database queries outside models are documented with justification or count is below threshold (e.g., <5 instances)
- All models define either `$fillable` or `$guarded` properties for mass assignment protection
- Public methods, relationships, and custom attributes are documented in PHPDoc blocks

<enforcement>
Claude Code MUST verify all Eloquent models conform to this standard before approving data access layer changes. Verification is mandatory and cannot be deferred.
</enforcement>
