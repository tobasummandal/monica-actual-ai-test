<rule_activation id="203f1528-9e41-4d93-93b9-67f52f24737c" title="Adopt PHP as Primary Backend Language for Laravel-Based Web Applications: Deployment Targets Include" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in the repository. Backend business logic, authentication, controllers, domain services, and tests MUST be implemented in PHP using Laravel framework conventions.
</rule_activation>

### Rules

- **R-PHP-001** MUST: Use PHP 8.0 or higher for all backend code. Specify minimum PHP version in composer.json platform requirements.
- **R-PHP-002** MUST: Ensure all required Laravel PHP extensions are installed and enabled (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath).
- **R-PHP-003** MUST: Write new backend code in PHP following Laravel conventions. Non-PHP backend components require architectural review board approval.
- **R-PHP-004** MUST: Backend business logic, authentication mechanisms (Fortify actions), web controllers, database migrations, ORM operations, and feature/unit tests MUST be implemented in PHP.
- **R-PHP-005** MAY: Deployment targets MAY include containerized environments (Docker) or traditional LAMP/LEMP stacks as long as PHP runtime requirements are satisfied.

### Verify

```bash
# Verify PHP version compatibility (8.0+)
php --version | grep -E 'PHP [8-9]\.' && echo 'PHP version compatible' || echo 'PHP version incompatible'

# Verify required Laravel PHP extensions are present
php -m | grep -E '(openssl|pdo|mbstring|tokenizer|xml|ctype|json|bcmath)' | wc -l | grep -E '[8-9]|[1-9][0-9]' && echo 'Required extensions present' || echo 'Missing extensions'

# Verify PHP files exist in app directory
find app/ -name '*.php' -type f | wc -l | grep -E '[1-9][0-9]*' && echo 'PHP files detected in app directory' || echo 'No PHP files found'
```

**Accept when:**
- PHP version check returns 8.0 or higher in all deployment environments
- All required Laravel PHP extensions (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) are installed and enabled
- Application backend code in app/ directory consists primarily of PHP files with .php extension
- Composer dependencies successfully install and application bootstraps without runtime errors
- New backend functionality is implemented in PHP following Laravel patterns (Actions, Controllers, Services, Domain models)

<enforcement>
Claude Code MUST NOT skip or defer verification. CI/CD pipeline MUST fail builds that introduce non-PHP backend code without architectural review approval. Deployment scripts MUST abort if target environment lacks required PHP version or extensions.
</enforcement>
