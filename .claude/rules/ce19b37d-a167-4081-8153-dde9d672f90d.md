<rule_activation id="ce19b37d-a167-4081-8153-dde9d672f90d" title="Adopt Mock-Based Unit Testing for External Service Dependencies in CI/CD Pipeline: Mock Expectations Verify" applies_to="**/*Test.php">
These rules are ALWAYS ACTIVE for all unit test files in the codebase. Mock-based testing is mandatory for external service dependencies to ensure fast, reliable, and deterministic CI/CD pipeline execution.
</rule_activation>

### Rules

- **R-MOCK-001** SHOULD: Mock expectations SHOULD verify that external service methods are called with correct parameters and in the expected order.

### Verify

```bash
# Verify no unmocked external service calls in unit tests
grep -r "new.*Client\|->connect\|->request" tests/Unit/ | grep -v "Mock\|Stub\|Fake" | wc -l

# Count unit test files using mocking patterns
find tests/Unit -name '*Test.php' -exec grep -l 'createMock\|getMockBuilder\|shouldReceive' {} \; | wc -l

# Verify no network-dependent tests in unit suite
phpunit --testsuite=unit --no-coverage --testdox | grep -i 'network\|connection\|timeout' || echo 'No network-dependent tests found'
```

**Accept when:**
- Unit tests execute successfully without network connectivity (verified by running tests with network disabled)
- Unit test suite completes in under 30 seconds for typical project size, indicating no real external service calls
- Grep verification shows that unit tests use mock/stub/fake patterns for external service dependencies
- CI/CD pipeline unit test stage has >95% success rate over 30-day period, indicating stable, non-flaky tests

<enforcement>
Claude Code MUST NOT skip or defer verification. All unit tests for external service dependencies MUST use mocking patterns. Code review MUST block merges of unit tests containing direct external service calls without documented exception approval. CI/CD pipeline MUST fail if unit tests exceed 30-second execution threshold, indicating potential real service calls.
</enforcement>
