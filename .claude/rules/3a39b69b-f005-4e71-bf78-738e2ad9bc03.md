<rule_activation id="3a39b69b-f005-4e71-bf78-738e2ad9bc03" title="Adopt PHP as Primary Backend Language for Laravel-Based Web Applications: Application Servers Use" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in the Laravel-based web application backend. PHP is the primary runtime for all backend business logic, authentication, domain services, controllers, database operations, and tests.
</rule_activation>

### Rules

- **R-PHP-001** SHOULD: Application servers SHOULD use PHP-FPM or similar process managers for optimal performance and resource management.

### Verify

```bash
# Verify PHP version compatibility (8.0+)
php --version | grep -E 'PHP [8-9]\.' && echo 'PHP version compatible' || echo 'PHP version incompatible'

# Verify required Laravel PHP extensions are installed
php -m | grep -E '(openssl|pdo|mbstring|tokenizer|xml|ctype|json|bcmath)' | wc -l | grep -E '[8-9]|[1-9][0-9]' && echo 'Required extensions present' || echo 'Missing extensions'

# Verify PHP files exist in app directory
find app/ -name '*.php' -type f | wc -l | grep -E '[1-9][0-9]*' && echo 'PHP files detected in app directory' || echo 'No PHP files found'
```

**Accept when:**
- PHP version check returns 8.0 or higher in all deployment environments
- All required Laravel PHP extensions (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) are installed and enabled
- Application backend code in app/ directory consists primarily of PHP files with .php extension
- Composer dependencies successfully install and application bootstraps without runtime errors

<enforcement>
Claude Code MUST verify PHP version compatibility and required extensions before approving backend code changes. Verification is mandatory and MUST NOT be skipped or deferred.
</enforcement>
