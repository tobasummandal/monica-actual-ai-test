<rule_activation id="45587d78-b197-4a35-8891-1f6ca5719e6f" title="Adopt PHP as Primary Backend Language for Laravel-Based Web Applications: Development Production Environments" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in the Laravel-based web application backend.
</rule_activation>

### Rules

- **R-PHP-001** SHOULD: Development and production environments SHOULD maintain PHP version parity to minimize deployment-related issues.
- **R-PHP-002** MUST: All backend business logic and domain services SHALL be implemented in PHP.
- **R-PHP-003** MUST: Authentication and authorization mechanisms (Fortify actions) SHALL be implemented in PHP.
- **R-PHP-004** MUST: Web controllers and HTTP request handling SHALL be implemented in PHP.
- **R-PHP-005** MUST: Database migrations and ORM operations SHALL be implemented in PHP.
- **R-PHP-006** MUST: Feature and unit tests for backend functionality SHALL be implemented in PHP.
- **R-PHP-007** MUST: API endpoints and web routes SHALL be implemented in PHP.
- **R-PHP-008** MUST: Specify minimum PHP version (8.0+) in composer.json platform requirements.
- **R-PHP-009** SHOULD: Use Laravel Sail or Docker Compose for local development to ensure environment parity with production.
- **R-PHP-010** SHOULD: Document required PHP extensions and configuration in deployment runbooks.
- **R-PHP-011** SHOULD: Implement automated testing in CI/CD against the target PHP version.
- **R-PHP-012** MAY: Consider using PHP-FPM with nginx or Apache for production deployments.

### Verify

```bash
# Verify PHP version compatibility (8.0 or higher)
php --version | grep -E 'PHP [8-9]\.' && echo 'PHP version compatible' || echo 'PHP version incompatible'

# Verify required Laravel PHP extensions are present
php -m | grep -E '(openssl|pdo|mbstring|tokenizer|xml|ctype|json|bcmath)' | wc -l | grep -E '[8-9]|[1-9][0-9]' && echo 'Required extensions present' || echo 'Missing extensions'

# Verify PHP files detected in app directory
find app/ -name '*.php' -type f | wc -l | grep -E '[1-9][0-9]*' && echo 'PHP files detected in app directory' || echo 'No PHP files found'
```

**Accept when:**
- PHP version check returns 8.0 or higher in all deployment environments
- All required Laravel PHP extensions (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) are installed and enabled
- Application backend code in app/ directory consists primarily of PHP files with .php extension
- Composer dependencies successfully install and application bootstraps without runtime errors

<enforcement>
Claude Code MUST verify PHP version compatibility and extension availability before approving backend code changes. Verification is mandatory and MUST NOT be skipped or deferred. CI/CD pipeline MUST fail builds that violate these rules.
</enforcement>
