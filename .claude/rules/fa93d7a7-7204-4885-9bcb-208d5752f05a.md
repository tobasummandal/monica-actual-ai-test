<rule_activation id="fa93d7a7-7204-4885-9bcb-208d5752f05a" title="Standardize Laravel Fortify for Authentication Runtime: Domain Services Not" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching `**/*`. Domain services MUST NOT implement custom password hashing, validation, or authentication logic that bypasses Laravel Fortify.
</rule_activation>

### Rules

- **R-FORTIFY-001** MUST_NOT: Domain services MUST NOT implement custom password hashing, validation, or authentication logic that bypasses Fortify
- **R-FORTIFY-002** MUST: Register all Fortify actions in the FortifyServiceProvider, mapping them to application-specific implementations in app/Actions/Fortify
- **R-FORTIFY-003** MUST: Domain services should inject Fortify action contracts rather than calling Fortify facades directly to maintain testability
- **R-FORTIFY-004** MUST: Use Fortify's validation rules and password validation configuration in config/fortify.php for consistent password policies
- **R-FORTIFY-005** MUST: Feature tests should use Fortify's test helpers and verify authentication state changes rather than testing Fortify internals

### Verify

```bash
# Check for direct password hashing outside Fortify
grep -r 'Hash::make\|Hash::check' app/Domains --exclude-dir=vendor | grep -v 'Fortify' || echo 'No direct password hashing found'

# Verify Fortify actions are registered
grep -r 'use Laravel\\Fortify' app/Actions/Fortify | wc -l

# Run authentication feature tests
php artisan test --filter=Auth --filter=Password --filter=Account
```

**Accept when:**
- No direct password hashing or authentication logic found in domain services outside Fortify actions
- All authentication actions are registered in FortifyServiceProvider and located in app/Actions/Fortify namespace
- Feature tests for authentication flows pass and verify Fortify integration

<enforcement>
Claude Code MUST NOT skip or defer verification. Violations are caught by automated static analysis, code review checklist, and CI pipeline authentication feature tests. Build fails if direct password hashing is detected outside Fortify actions.
</enforcement>
