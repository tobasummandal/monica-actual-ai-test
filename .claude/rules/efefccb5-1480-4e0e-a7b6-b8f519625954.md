<rule_activation id="efefccb5-1480-4e0e-a7b6-b8f519625954" title="Adopt PHPUnit for Unit Testing in Domain-Driven Architecture: Each Service Class" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in domain-driven PHP applications using PHPUnit for unit testing.
</rule_activation>

### Rules

- **R-PHPUNIT-001** SHOULD: Each service class, controller, and view helper SHOULD have a corresponding unit test file.
- **R-PHPUNIT-002** SHOULD: Unit test files SHOULD follow the `{ClassName}Test.php` naming convention.
- **R-PHPUNIT-003** SHOULD: Test directory structure SHOULD mirror the application domain hierarchy under `tests/Unit/Domains/`.
- **R-PHPUNIT-004** SHOULD: Unit tests SHOULD use PHPUnit's TestCase framework and extend `PHPUnit\Framework\TestCase`.
- **R-PHPUNIT-005** SHOULD: Tests SHOULD focus on isolated unit testing of individual service layer components, controllers, and helpers.
- **R-PHPUNIT-006** MUST: Integration tests requiring database connections MUST be excluded from the unit test suite.
- **R-PHPUNIT-007** MUST: End-to-end tests, browser-based functional tests, and performance tests MUST be excluded from unit test scope.

### Verify

```bash
# Count test files in domain structure
find tests/Unit/Domains -name '*Test.php' -type f | wc -l

# Verify PHPUnit TestCase usage
grep -r 'use PHPUnit\\Framework\\TestCase' tests/Unit/Domains/ | wc -l

# Execute unit test suite with test documentation
vendor/bin/phpunit --testsuite=unit --testdox
```

**Accept when:**
- All test files in `tests/Unit/Domains/` follow the `{ClassName}Test.php` naming convention
- PHPUnit test execution completes successfully with all tests passing
- Test directory structure mirrors the application domain hierarchy under `tests/Unit/Domains/`
- All service classes, controllers, and view helpers have corresponding test files
- Code coverage reports are generated and tracked during CI builds

<enforcement>
Claude Code MUST verify all rules before accepting changes to test structure, service classes, controllers, or view helpers. Verification is mandatory and MUST NOT be skipped or deferred.
