<rule_activation id="b7e5fc35-6aa6-4382-8996-054624f6fd77" title="Adopt Modular Architecture with Factory-Based Component Generation: Console Commands Application" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in the application to enforce modular architecture with factory-based component generation across Console Commands, Database Factories, View Helpers, and Domain-Driven Module Organization.
</rule_activation>

### Rules

- **R-MOD-001** MUST: Console commands for application setup and initialization MUST be implemented in `app/Console/Commands/` and follow the Command pattern.
- **R-MOD-002** MUST: All PHP files in `app/Domains` directory MUST use the correct `App\Domains` namespace hierarchy.
- **R-MOD-003** MUST: All factory classes in `database/factories` MUST extend the framework's base Factory class.
- **R-MOD-004** MUST: All setup commands in `app/Console/Commands` MUST extend the framework's Command class and follow naming conventions.
- **R-MOD-005** SHOULD: Domain names should be singular nouns (Contact, not Contacts); subdomain names should describe the capability (ManageContact); layer names should be standard (Web, Console, Database).
- **R-MOD-006** SHOULD: Module dependencies SHOULD be documented in a central registry or dependency graph to prevent circular dependencies and clarify initialization order.
- **R-MOD-007** SHOULD: Factory classes SHOULD be updated as part of definition of done for model changes.
- **R-MOD-008** MAY: Simplified approach MAY be used for simple CRUD modules when full modular structure is not required, subject to architecture review.

### Verify

```bash
# Verify all PHP files in app/Domains use correct namespace
find app/Domains -type f -name '*.php' | xargs grep -L 'namespace App\\Domains' | wc -l | grep -q '^0$'

# Verify all factory classes extend base Factory class
find database/factories -type f -name '*Factory.php' | xargs grep -c 'extends Factory' | grep -v ':0'

# Verify all setup commands extend Command class
find app/Console/Commands -type f -name 'Setup*.php' | xargs grep -c 'extends Command' | grep -v ':0'
```

**Accept when:**
- All PHP files in `app/Domains` directory use the correct `App\Domains` namespace hierarchy
- All factory classes in `database/factories` extend the framework's base Factory class
- All setup commands in `app/Console/Commands` extend the framework's Command class and follow naming conventions
- Namespace conventions are verified by automated CI pipeline checks using PHPStan or Psalm
- Code review checklist confirms module structure compliance
- Pre-commit hooks validate file placement and class naming patterns

Claude Code MUST NOT skip or defer verification. CI pipeline MUST fail if namespace conventions are violated, blocking merge. Code review approval MUST be withheld until module structure compliance is achieved. Technical debt tickets MUST be created for legacy code violations with prioritized remediation plan.
</enforcement>
