<rule_activation id="a8d44ae5-80fb-414f-8b08-782ebbb64261" title="Use Laravel Hash Facade for Password Credential Storage: Password Credentials Hashed" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching `**/*`. All password credentials MUST be hashed using Laravel's Hash facade before storage in the database across all user account creation workflows, password reset and recovery flows, password update and change operations, and user invitation acceptance with password setting.
</rule_activation>

### Rules

- **R-HASH-001** MUST: All password credentials MUST be hashed using Laravel's Hash facade before storage in the database.

### Verify

```bash
# Verify Hash::make usage in authentication files
grep -r "Hash::make" app/ --include="*.php" | wc -l

# Verify no direct password_hash usage found in application code
grep -r "password_hash" app/ --include="*.php" || echo "No direct password_hash usage found (good)"

# Verify no plain-text password assignments
grep -r "'password'.*=>.*\$" app/ --include="*.php" | grep -v "Hash::make" | grep -v "bcrypt" || echo "No plain-text password assignments found (good)"

# Verify Hash facade configuration
php artisan tinker --execute="echo config('hashing.driver');"
```

**Accept when:**
- All password storage operations use Hash::make() as verified by grep showing consistent usage across authentication files
- No direct password_hash() calls found in application code (framework usage only)
- Hash facade configuration is properly set in config/hashing.php with bcrypt or argon2id driver
- Test suite includes verification that passwords are hashed before database storage

<enforcement>
Claude Code MUST NOT skip or defer verification. All password credential storage MUST use Laravel's Hash facade. CI pipeline MUST fail if plain-text password storage patterns are detected. Pull requests MUST be blocked until Hash facade usage is corrected.
</enforcement>
