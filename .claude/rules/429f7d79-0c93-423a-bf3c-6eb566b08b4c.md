<rule_activation id="429f7d79-0c93-423a-bf3c-6eb566b08b4c" title="Standardize PHPUnit Test Structure with setUp and Trait-Based Helpers: Tests Use Factory" applies_to="tests/Unit/**/*Test.php">
These rules are ALWAYS ACTIVE for all PHPUnit unit test files in the tests/Unit/ directory.
</rule_activation>

### Rules

- **R-PHPUNIT-001** MAY: Tests MAY use factory patterns or fixtures for test data generation to improve maintainability.
- **R-PHPUNIT-002** SHOULD: Test classes SHOULD extend PHPUnit\Framework\TestCase or a documented base test class.
- **R-PHPUNIT-003** SHOULD: Test files SHOULD contain a setUp() method or explicitly document why it's not needed.
- **R-PHPUNIT-004** SHOULD: Test file names SHOULD match the pattern {ClassName}Test.php and be organized in directories mirroring the application structure.
- **R-PHPUNIT-005** SHOULD: Shared test utilities SHOULD be implemented as traits to promote DRY principles and reduce code duplication.
- **R-PHPUNIT-006** SHOULD: Traits SHOULD be focused on single responsibilities and remain stateless where possible.

### Verify

```bash
# Count test files without setUp() method
find tests/Unit -name '*Test.php' -type f | xargs grep -L 'function setUp' | wc -l

# Count test classes not extending PHPUnit\Framework\TestCase
grep -r 'class.*Test extends' tests/Unit/ | grep -v 'PHPUnit\\Framework\\TestCase' | wc -l

# Count non-test PHP files in tests/Unit (should be minimal)
find tests/Unit -type f -name '*.php' ! -name '*Test.php' | wc -l
```

**Accept when:**
- All test files in tests/Unit/ contain a setUp() method or explicitly document why it's not needed
- All test classes extend PHPUnit\Framework\TestCase or a documented base test class
- Test file names match the pattern {ClassName}Test.php and are organized in directories mirroring the application structure
- Factory patterns or fixtures are used for test data generation where applicable
- Shared test traits are focused on single responsibilities
