<rule_activation id="69924778-4cf1-477d-8cc9-b936643f19c1" title="Standardize Authentication Middleware for Journal Management Controllers: Individual Route Methods" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in the codebase.

**Scope:**
- All HTTP controllers in app/Domains/Vault/ManageJournals/Web/Controllers
- Journal, Post, Photo, Metric, and SliceOfLife resource controllers
- Any new controllers added to the ManageJournals domain
- Authentication middleware configuration and method selection

**Out of scope:**
- Controllers outside the ManageJournals domain
- API controllers with different authentication schemes (e.g., token-based)
- Public-facing controllers that intentionally allow unauthenticated access
- Authorization logic beyond authentication (handled separately)
- Service layer authentication (handled at controller boundary)

**Exception:** EXC-001: A controller method explicitly requires public access for specific business requirements (e.g., public journal sharing)
</rule_activation>

### Rules

**Note:** The source ADR contains only one explicit policy statement in the Decision section.

- **R-AUTH-001** MAY: Individual route methods MAY apply additional authorization checks beyond the base authentication middleware.

### Context

This ADR standardizes authentication middleware patterns across journal management controllers in the Vault domain. While the ADR primarily documents that additional authorization checks are permitted at the route method level, the broader context indicates that all controllers in `app/Domains/Vault/ManageJournals/Web/Controllers` should maintain consistent authentication middleware configuration.

### Verify

```bash
# Count constructors in ManageJournals controllers
grep -r "__construct" app/Domains/Vault/ManageJournals/Web/Controllers/*.php | wc -l

# Count middleware references (excluding comments)
grep -r "middleware" app/Domains/Vault/ManageJournals/Web/Controllers/*.php | grep -v "//" | wc -l

# Find controllers without middleware configuration
find app/Domains/Vault/ManageJournals/Web/Controllers -name "*Controller.php" -exec grep -L "middleware" {} \;
```

**Accept when:**
- All controller files in app/Domains/Vault/ManageJournals/Web/Controllers contain authentication middleware configuration
- The grep command for middleware references returns a count equal to or greater than the number of controller files
- The find command searching for controllers without middleware returns no results (empty output)

<enforcement>
Claude Code MUST verify authentication middleware presence in ManageJournals controllers when:
- Creating new controllers in app/Domains/Vault/ManageJournals/Web/Controllers
- Modifying existing controllers in the ManageJournals domain
- Reviewing pull requests that add or modify journal management endpoints

Verification is automated via CI pipeline and code review checklist. Violations block pull requests until corrected.
</enforcement>
