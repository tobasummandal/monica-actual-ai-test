<rule_activation id="42560c4b-d76b-428f-afaf-f1a7eccf4251" title="Adopt PHP as Primary Backend Language for Laravel-Based Web Applications: Backend Application Code" applies_to="**/*">
These rules are ALWAYS ACTIVE for all backend application code. All backend business logic, authentication mechanisms, web controllers, database operations, and API endpoints must be written in PHP to ensure consistent runtime environment and deployment target compatibility with Laravel framework.
</rule_activation>

### Rules

- **R-PHP-001** MUST: All backend application code MUST be written in PHP to ensure consistent runtime environment and deployment target compatibility.

**In scope:**
- All backend business logic and domain services
- Authentication and authorization mechanisms (Fortify actions)
- Web controllers and HTTP request handling
- Database migrations and ORM operations
- Feature and unit tests for backend functionality
- API endpoints and web routes

**Out of scope:**
- Frontend JavaScript/TypeScript code executed in browser
- Build tools and asset compilation (npm, webpack, vite)
- Infrastructure-as-code scripts (Terraform, Ansible)
- CI/CD pipeline scripts (bash, yaml configurations)
- Database stored procedures or functions written in SQL dialects

- **R-PHP-002** MUST: Minimum PHP version 8.0 or higher MUST be specified in composer.json platform requirements.

- **R-PHP-003** MUST: All required Laravel PHP extensions (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) MUST be installed and enabled in deployment environments.

### Verify

```bash
# Verify PHP version compatibility (8.0 or higher)
php --version | grep -E 'PHP [8-9]\.' && echo 'PHP version compatible' || echo 'PHP version incompatible'

# Verify required PHP extensions are present
php -m | grep -E '(openssl|pdo|mbstring|tokenizer|xml|ctype|json|bcmath)' | wc -l | grep -E '[8-9]|[1-9][0-9]' && echo 'Required extensions present' || echo 'Missing extensions'

# Verify PHP files are present in app directory
find app/ -name '*.php' -type f | wc -l | grep -E '[1-9][0-9]*' && echo 'PHP files detected in app directory' || echo 'No PHP files found'
```

**Accept when:**
- PHP version check returns 8.0 or higher in all deployment environments
- All required Laravel PHP extensions (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) are installed and enabled
- Application backend code in app/ directory consists primarily of PHP files with .php extension
- Composer dependencies successfully install and application bootstraps without runtime errors

<enforcement>
Claude Code MUST NOT skip or defer verification. CI/CD pipeline checks, code review processes, and deployment validation scripts verify compliance. Violations result in build failures, deployment aborts, and pull request rejections. Exceptions for non-PHP backend components require architectural review board approval with documented justification demonstrating clear technical necessity that PHP cannot address.
</enforcement>
