<rule_activation id="ce630fe3-deb7-4e5b-920a-d4dc4a384ce7" title="Adopt Eloquent ORM Models as Standard Data Access Layer: Eloquent Relationships Hasmany" applies_to="**/*">
These rules are ALWAYS ACTIVE for all database-backed entities in the application. All data access operations MUST use Eloquent ORM models as the primary abstraction layer.
</rule_activation>

### Rules

- **R-ELOQUENT-001** SHOULD: Eloquent relationships (hasMany, belongsTo, belongsToMany, etc.) SHOULD be defined as methods within the model class rather than using manual joins.

### Verify

```bash
# Verify all models extend Eloquent Model
grep -r 'extends Model' app/Models/ | wc -l

# Find models not in correct namespace
find app/Models -type f -name '*.php' | xargs grep -L 'namespace App\\Models'

# List all models and their database tables
php artisan model:show --all | grep -E '(Table|Database)'

# Detect direct DB facade calls in application layer (excluding approved exceptions)
grep -r 'DB::select\|DB::insert\|DB::update\|DB::delete' app/Http/Controllers/ app/Services/ | grep -v 'raw query approved'
```

**Accept when:**
- All model files exist in app/Models namespace and extend Illuminate\Database\Eloquent\Model
- No direct DB facade calls for CRUD operations found in controllers or services (excluding approved exceptions)
- Model count matches database table count for domain entities (excluding pivot tables and migrations table)
- All models define either $fillable or $guarded properties for mass assignment protection
- Eloquent relationships are defined as methods within model classes rather than using manual joins

<enforcement>
Claude Code MUST verify compliance with these rules before accepting changes to database access patterns. Violations must be flagged and remediated according to the enforcement policy: CI pipeline fails if direct DB facade calls detected without exception documentation, pull requests blocked until models are created for new database tables, and violations flagged in code review with required remediation before merge.
</enforcement>
