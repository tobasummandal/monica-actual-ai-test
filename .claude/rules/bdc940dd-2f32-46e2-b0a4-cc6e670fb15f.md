<rule_activation id="bdc940dd-2f32-46e2-b0a4-cc6e670fb15f" title="Adopt Mock-Based Unit Testing for External Service Dependencies in CI/CD Pipeline: Unit Tests Not" applies_to="**/*Test.php">
These rules are ALWAYS ACTIVE for all unit test files in the codebase. Unit tests MUST use mock-based testing for external service dependencies to ensure fast, reliable, and deterministic execution in CI/CD pipelines.
</rule_activation>

### Rules

- **R-MOCK-001** MUST: Unit tests MUST NOT require network connectivity, external service availability, or real credentials to execute successfully.

### Verify

```bash
# Check for unmocked external service calls in unit tests
grep -r "new.*Client\|->connect\|->request" tests/Unit/ | grep -v "Mock\|Stub\|Fake" | wc -l

# Verify mocking patterns are used in unit tests
find tests/Unit -name '*Test.php' -exec grep -l 'createMock\|getMockBuilder\|shouldReceive' {} \; | wc -l

# Verify no network-dependent tests in unit suite
phpunit --testsuite=unit --no-coverage --testdox | grep -i 'network\|connection\|timeout' || echo 'No network-dependent tests found'
```

**Accept when:**
- Unit tests execute successfully without network connectivity (verified by running tests with network disabled)
- Unit test suite completes in under 30 seconds for typical project size, indicating no real external service calls
- Grep verification shows that unit tests use mock/stub/fake patterns for external service dependencies
- CI/CD pipeline unit test stage has >95% success rate over 30-day period, indicating stable, non-flaky tests

<enforcement>
Claude Code MUST NOT skip or defer verification. All unit tests MUST be verified to use mocking patterns before approval. Code review MUST block merges that violate R-MOCK-001. CI/CD pipeline MUST fail if unit tests exceed execution time thresholds or contain direct external service calls.
</enforcement>
