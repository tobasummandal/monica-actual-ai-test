<rule_activation id="d031242b-0a27-4227-8bff-b89ec676f543" title="Adopt Domain-Driven Module Boundaries with External API Integration Layers: Data Transfer Between" applies_to="**/*">
These rules are ACTIVE for all external API integrations, third-party service integrations, data import/export operations, and public API endpoints.

**In scope:**
- All external API integrations including REST, SOAP, WebDAV, CardDAV, and other protocol-based communications
- Third-party service integrations that require protocol-specific client implementations
- Data import/export operations involving external standards or formats
- Public API endpoints that expose domain functionality to external consumers

**Out of scope:**
- Internal service-to-service communication within the same application boundary
- Database access layers and repository patterns
- Framework-level HTTP routing and middleware
- Authentication and authorization mechanisms (unless specific to external API integration)

**Exceptions:**
- EXC-001: Legacy integrations predating this ADR that require significant refactoring effort
- EXC-002: Proof-of-concept or experimental integrations in non-production environments
</rule_activation>

### Rules

- **R-DDM-001** MUST: Data transfer between external APIs and domain logic MUST use dedicated DTO (Data Transfer Object) classes located in Services/Utils/Model directories.

- **R-DDM-002** MUST: Backend interface contracts MUST be defined before implementing concrete clients to ensure testability from the start.

- **R-DDM-003** MUST: Backend implementations MUST be provided to domain services via dependency injection, enabling easy substitution for testing.

- **R-DDM-004** SHOULD: DTOs SHOULD match external API schemas closely, with separate mapper classes to transform between DTOs and domain entities.

- **R-DDM-005** MUST: External API integration modules MUST follow domain-based directory structure: {Domain}/{IntegrationName}/Services, /Utils/Model, /Web/Backend.

- **R-DDM-006** MUST: Core domain entity and business logic classes MUST NOT contain direct external protocol library usage.

- **R-DDM-007** MUST: All data exchange with external APIs MUST use dedicated DTO classes rather than direct domain entity serialization.

### Verify

```bash
# Count backend interfaces and implementations
find app/Domains -type f -name '*Client*' -o -name '*Backend*' | xargs grep -l 'interface\|implements' | wc -l

# Count DTO classes in proper location
find app/Domains -path '*/Services/Utils/Model/*Dto.php' | wc -l

# Check for direct external protocol usage in core domain classes (should return 0)
grep -r 'use.*\\Dav\\' app/Domains --include='*.php' | grep -v 'DavClient\|Dav/' | wc -l
```

**Accept when:**
- All external API integration modules follow the domain-based directory structure with dedicated Services and Utils/Model subdirectories
- Backend interfaces exist for all external protocol implementations and are used via dependency injection
- No direct external protocol library usage is found in core domain entity or business logic classes (grep verification returns 0 violations)
- All data exchange with external APIs uses dedicated DTO classes rather than direct domain entity serialization

<enforcement>
Claude Code MUST verify compliance with these rules for all external API integration implementations. Verification is mandatory and enforced through:
- Automated CI pipeline checks using grep and find commands to detect pattern violations
- Code review checklist items covering external API integration structure
- Architecture decision review for new external integrations before implementation

Violations trigger:
- CI pipeline failure if direct external protocol usage is detected in core domain classes
- Code review blocks for merge requests that don't follow the established module structure
- Technical debt logging for existing violations with prioritized remediation plans

Exception requests must be submitted to architecture review board with justification and impact analysis, evaluated within 2 business days, and reviewed after 6 months.
</enforcement>
