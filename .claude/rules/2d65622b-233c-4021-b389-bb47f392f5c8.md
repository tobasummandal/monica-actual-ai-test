These rules are ALWAYS ACTIVE for all Eloquent model files in the app/Models namespace.
</rule_activation>

### Rules

- **R-ELOQUENT-001** MUST: Each model MUST correspond to a single database table with explicit or conventional table name mapping.
- **R-ELOQUENT-002** MUST: All model files in app/Models MUST extend Illuminate\Database\Eloquent\Model.
- **R-ELOQUENT-003** MUST: Models MUST define either $fillable or $guarded properties for mass assignment protection.
- **R-ELOQUENT-004** SHOULD: Define relationships using type-hinted return types (e.g., public function posts(): HasMany) for better IDE support and static analysis.
- **R-ELOQUENT-005** SHOULD: Use model factories for testing to ensure consistent test data generation across the test suite.
- **R-ELOQUENT-006** SHOULD: Document complex query scopes and custom accessors with PHPDoc blocks explaining their purpose and usage.
- **R-ELOQUENT-007** SHOULD: Consider using model observers for cross-cutting concerns like logging, caching, or event dispatching rather than cluttering model methods.
- **R-ELOQUENT-008** SHOULD: Enforce eager loading in code reviews to prevent N+1 query problems.
- **R-ELOQUENT-009** SHOULD: Refactor models exceeding 300 lines to maintain single responsibility principle.
- **R-ELOQUENT-010** MAY: Use raw SQL queries or Query Builder directly for legacy database schemas or complex read-only reporting queries (document with EXC-ID reference).

### Verify

```bash
# Count models extending Eloquent Model
grep -r "extends Model" app/Models/ | wc -l

# Find models missing proper namespace
find app/Models -name '*.php' -exec grep -L 'namespace App\\Models' {} \;

# List all model classes
php artisan model:show --all 2>&1 | grep -c 'class'

# Count direct database queries outside models (excluding documented exceptions)
grep -r "DB::table\|DB::select" app/Http app/Services | grep -v "// Exception" | wc -l
```

**Accept when:**
- All model files in app/Models extend Illuminate\Database\Eloquent\Model
- At least 7 model classes exist matching the detected pattern (File, PostTemplateSection, ContactInformationType, GiftOccasion, CallReasonType, Account, QuickFact)
- Models define either $fillable or $guarded properties for mass assignment protection
- Direct database queries outside models are documented with exception justifications (EXC-001, EXC-002)
- Models are located in app/Models namespace with proper naming conventions
