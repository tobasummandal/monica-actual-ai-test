<rule_activation id="4033e547-681d-462f-b7f2-0bd187f9ccf8" title="Adopt Domain-Driven Controller Organization for Journal Management: Each Distinct Entity" applies_to="app/Domains/Vault/ManageJournals/Web/Controllers/**/*Controller.php">
These rules are ALWAYS ACTIVE for all web controllers within the Vault domain's ManageJournals bounded context.
</rule_activation>

### Rules

- **R-JOURNAL-001** MUST: Each distinct entity or concern within journal management (journals, posts, photos, metrics, slices of life) MUST have a dedicated controller class.
- **R-JOURNAL-002** MUST: All controller files in the ManageJournals domain MUST be located under `app/Domains/Vault/ManageJournals/Web/Controllers`.
- **R-JOURNAL-003** MUST: Each controller MUST have a single, clear responsibility corresponding to an entity or entity-concern combination.
- **R-JOURNAL-004** MUST: Controller namespaces MUST match their directory structure and follow the established pattern: `App\Domains\Vault\ManageJournals\Web\Controllers`.
- **R-JOURNAL-005** MUST: Route definitions MUST correctly reference controllers using the domain-based namespace.

### Verify

```bash
# Count controller files in the ManageJournals domain
find app/Domains/Vault/ManageJournals/Web/Controllers -name '*Controller.php' | wc -l

# Verify all controllers use correct namespace
grep -r 'namespace App\\Domains\\Vault\\ManageJournals\\Web\\Controllers' app/Domains/Vault/ManageJournals/Web/Controllers/*.php | wc -l

# Verify routes reference correct controller namespace
php artisan route:list --path=journal --columns=Action | grep 'App\\Domains\\Vault\\ManageJournals\\Web\\Controllers'
```

**Accept when:**
- All controller files in the ManageJournals domain are located under `app/Domains/Vault/ManageJournals/Web/Controllers`
- Each controller has a single, clear responsibility corresponding to an entity or entity-concern combination
- Controller namespaces match their directory structure and follow the established pattern
- Route definitions correctly reference controllers using the domain-based namespace
- No controllers exist outside the designated domain structure (except approved exceptions EX-001 and EX-002)
