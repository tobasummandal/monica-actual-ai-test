These rules are ALWAYS ACTIVE for all files in the Vault domain's ManageJournals subdomain and related journal management operations.

### Rules

- **R-DDD-001** MUST: Domain operations MUST be organized by subdomain (ManageJournals) with clear namespace boundaries separating Web, Services, and other concerns.
- **R-DDD-002** MUST: Service classes MUST use verb-noun naming convention (e.g., CreatePost, UpdateMetric, RemoveTag) to clearly communicate intent.
- **R-DDD-003** MUST: Controllers MUST remain thin and delegate to services rather than implementing business logic directly.
- **R-DDD-004** MUST: Services MUST accept primitive types or DTOs as parameters rather than HTTP request objects to maintain independence from web layer.
- **R-DDD-005** SHOULD: Services SHOULD use dependency injection for service dependencies to improve testability and enable mocking.
- **R-DDD-006** SHOULD: Related services SHOULD be grouped in subdirectories if a domain grows large (e.g., ManageJournals/Services/Posts, ManageJournals/Services/Metrics).
- **R-DDD-007** SHOULD: Service classes SHOULD encapsulate meaningful business logic, validation, or orchestration rather than acting as simple pass-through to models.

### Verify

```bash
# Count service files in domain directories
find app/Domains/*/Services -type f -name '*.php' | wc -l

# Count controller classes in ManageJournals subdomain
grep -r 'class.*Controller' app/Domains/Vault/ManageJournals/Web/Controllers | wc -l

# Verify Services namespace organization
grep -r 'namespace.*Services' app/Domains/Vault/ManageJournals/Services | head -5
```

**Accept when:**
- Service classes exist in dedicated Services directories within domain boundaries
- Controllers delegate to services rather than implementing business logic directly
- Service class names follow verb-noun convention and implement single-responsibility operations
- Business logic is centralized in service layer, not scattered across controllers or models
- Services accept parameters independent of HTTP request objects
