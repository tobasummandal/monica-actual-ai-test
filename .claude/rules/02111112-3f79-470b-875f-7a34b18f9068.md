<rule_activation id="02111112-3f79-470b-875f-7a34b18f9068" title="Adopt Domain-Driven Test Organization with Mirrored Directory Structure: Test File Names" applies_to="tests/Unit/Domains/**/*.php">
These rules are ALWAYS ACTIVE for all test files under the domain-driven test organization structure.
</rule_activation>

### Rules

- **R-DDT-001** MUST: Test file names MUST follow the pattern {ClassName}Test.php, where {ClassName} is the exact name of the class under test.
- **R-DDT-002** MUST: All unit tests for domain-driven code organized under Domains/ directory MUST maintain a mirrored directory structure that corresponds to production code paths.
- **R-DDT-003** MUST: Test file namespaces MUST mirror production code namespaces with Tests\Unit prefix.
- **R-DDT-004** SHOULD: Service layer tests, controller tests, and view helper tests SHOULD follow the mirrored directory convention for both API and Web presentation layers.
- **R-DDT-005** MAY: Shared test utilities or abstract test base classes that support multiple domains MAY be organized separately with documented exceptions.
- **R-DDT-006** MAY: Legacy code being gradually migrated to domain-driven structure MAY use alternative organization with explicit exception documentation.

### Verify

```bash
# Verify all test files have corresponding production files
find tests/Unit/Domains -name '*Test.php' | while read test; do
  src=$(echo $test | sed 's|tests/Unit/||' | sed 's|Test.php|.php|')
  [ -f "src/$src" ] || echo "Orphaned test: $test"
done

# Verify test namespaces match directory structure
grep -r 'namespace.*Tests\\Unit\\Domains' tests/Unit/Domains --include='*.php' | awk -F: '{print $1}' | while read f; do
  ns=$(grep namespace $f | head -1 | sed 's/.*namespace //;s/;//')
  path=$(echo $ns | sed 's/\\/\//g' | sed 's/Tests\/Unit\///')
  expected="tests/Unit/$path"
  actual=$(dirname $f)
  [ "$expected" = "$actual" ] || echo "Mismatch: $f"
done

# Verify all tests follow mirrored structure pattern
phpunit --list-tests-xml | xmllint --xpath '//testCaseClass/@file' - | grep -v 'tests/Unit/Domains/.*/.*Test.php' && echo 'Non-conforming test locations found' || echo 'All tests follow mirrored structure'
```

**Accept when:**
- All test files under tests/Unit/Domains/ have corresponding production files in src/Domains/ with matching directory paths
- Test file namespaces match the directory structure and mirror production code namespaces with Tests\Unit prefix
- CI pipeline successfully executes domain-specific test suites using directory-based filtering
- No orphaned test files exist without corresponding production code
- All test files follow the {ClassName}Test.php naming pattern exactly
- Test file locations are validated by automated CI checks before merge
