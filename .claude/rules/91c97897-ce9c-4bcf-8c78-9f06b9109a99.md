<rule_activation id="91c97897-ce9c-4bcf-8c78-9f06b9109a99" title="Adopt PHPUnit for Unit Testing in Domain-Driven Architecture: Tests Use Phpunit" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in the codebase to ensure consistent unit testing practices using PHPUnit in a domain-driven architecture.
</rule_activation>

### Rules

- **R-PHPUNIT-001** MAY: Tests MAY use PHPUnit mocking capabilities to isolate dependencies
- **R-PHPUNIT-002** MUST: Unit tests for service layer components in all domains use PHPUnit
- **R-PHPUNIT-003** MUST: Unit tests for API controllers use PHPUnit
- **R-PHPUNIT-004** MUST: Unit tests for web view helpers use PHPUnit
- **R-PHPUNIT-005** MUST: Test files follow the {ClassName}Test.php naming convention
- **R-PHPUNIT-006** MUST: Test directory structure mirrors the application domain hierarchy under tests/Unit/Domains/
- **R-PHPUNIT-007** MUST NOT: Integration tests requiring database connections be included in unit test suites
- **R-PHPUNIT-008** MUST NOT: End-to-end tests requiring full application stack be included in unit test suites
- **R-PHPUNIT-009** MUST NOT: Browser-based functional tests be included in unit test suites

### Verify

```bash
# Count test files in domain structure
find tests/Unit/Domains -name '*Test.php' -type f | wc -l

# Verify PHPUnit TestCase usage
grep -r 'use PHPUnit\\Framework\\TestCase' tests/Unit/Domains/ | wc -l

# Execute PHPUnit test suite
vendor/bin/phpunit --testsuite=unit --testdox
```

**Accept when:**
- All test files in tests/Unit/Domains/ follow the {ClassName}Test.php naming convention
- PHPUnit test execution completes successfully with all tests passing
- Test directory structure mirrors the application domain hierarchy under tests/Unit/Domains/
- Code coverage reports are generated and tracked during CI builds
- All new components have corresponding unit tests

<enforcement>
Claude Code MUST NOT skip or defer verification of PHPUnit test execution and naming conventions. All unit tests MUST pass before code is accepted.
</enforcement>
