<rule_activation id="fd4c0958-1984-4239-bf9c-5160d05f9a67" title="Adopt Eloquent ORM Models as Standard Data Access Layer: Relationships Between Entities" applies_to="app/Models/**/*.php">
These rules are ALWAYS ACTIVE for all Eloquent model files in the application. Relationships between entities MUST be defined using Eloquent ORM relationship methods to maintain consistency, type safety, and architectural standardization across the codebase.
</rule_activation>

### Rules

- **R-ELOQUENT-001** SHOULD: Relationships between entities SHOULD be defined using Eloquent relationship methods (hasMany, belongsTo, belongsToMany, etc.)
- **R-ELOQUENT-002** MUST: All model files in app/Models MUST extend Illuminate\Database\Eloquent\Model
- **R-ELOQUENT-003** MUST: Models MUST define either $fillable or $guarded properties for mass assignment protection
- **R-ELOQUENT-004** SHOULD: Define relationships using type-hinted return types (e.g., public function posts(): HasMany) for better IDE support and static analysis
- **R-ELOQUENT-005** SHOULD: Document complex query scopes and custom accessors with PHPDoc blocks explaining their purpose and usage
- **R-ELOQUENT-006** SHOULD: Use model observers for cross-cutting concerns like logging, caching, or event dispatching rather than cluttering model methods
- **R-ELOQUENT-007** SHOULD: Establish service layer pattern for complex business logic to prevent model classes from exceeding 300 lines
- **R-ELOQUENT-008** MUST: Direct database queries outside models MUST be documented with exception justifications (EXC-ID reference)

### Verify

```bash
# Verify all models extend Eloquent Model
grep -r "extends Model" app/Models/ | wc -l

# Find models missing proper namespace
find app/Models -name '*.php' -exec grep -L 'namespace App\\Models' {} \;

# Count total model classes
php artisan model:show --all 2>&1 | grep -c 'class'

# Find direct database queries outside models (excluding documented exceptions)
grep -r "DB::table\|DB::select" app/Http app/Services | grep -v "// Exception" | wc -l
```

**Accept when:**
- All model files in app/Models extend Illuminate\Database\Eloquent\Model
- At least 7 model classes exist matching the detected pattern (File, PostTemplateSection, ContactInformationType, GiftOccasion, CallReasonType, Account, QuickFact)
- Models define either $fillable or $guarded properties for mass assignment protection
- Direct database queries outside models are documented with exception justifications
- Relationships are defined using Eloquent relationship methods with type hints
- No models exceed 300 lines of code without documented service layer extraction
