### Rules

- **R-ELO-001** SHOULD: Relationships between entities SHOULD be defined using Eloquent relationship methods (hasMany, belongsTo, belongsToMany, etc.)
- **R-ELO-002** MUST: All model files in app/Models MUST extend Illuminate\Database\Eloquent\Model
- **R-ELO-003** MUST: Models MUST define either $fillable or $guarded properties for mass assignment protection
- **R-ELO-004** SHOULD: Direct database queries outside models SHOULD be documented with exception justifications (using EXC-ID references)

### Verify

```bash
# Check that models extend Eloquent Model
grep -r "extends Model" app/Models/ | wc -l

# Find models missing proper namespace
find app/Models -name '*.php' -exec grep -L 'namespace App\\Models' {} \;

# Count model classes
php artisan model:show --all 2>&1 | grep -c 'class'

# Find direct database queries outside models without exception comments
grep -r "DB::table\|DB::select" app/Http app/Services | grep -v "// Exception" | wc -l
```

**Accept when:**
- All model files in app/Models extend Illuminate\Database\Eloquent\Model
- At least 7 model classes exist matching the detected pattern (File, PostTemplateSection, ContactInformationType, GiftOccasion, CallReasonType, Account, QuickFact)
- Models define either $fillable or $guarded properties for mass assignment protection
- Direct database queries outside models are documented with exception justifications
