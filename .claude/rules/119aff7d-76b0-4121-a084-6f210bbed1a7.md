<rule_activation id="119aff7d-76b0-4121-a084-6f210bbed1a7" title="Adopt Domain-Driven Service Layer Architecture for Business Operations: Business Operations Implemented" applies_to="**/*.php">
These rules are ALWAYS ACTIVE for all PHP files in the application. Business operations must follow domain-driven service layer architecture with clear separation between presentation logic (controllers) and domain logic (services).
</rule_activation>

### Rules

- **R-DDD-001** MUST: Business operations MUST be implemented as dedicated service classes within domain-specific namespaces (e.g., app/Domains/{Domain}/{Feature}/Services/)
- **R-DDD-002** MUST: Service classes MUST be named after the business operation they perform (e.g., CreateAccount, AcceptInvitation)
- **R-DDD-003** MUST: Controllers MUST be placed in app/Domains/{Domain}/{Feature}/Web/Controllers/ subdirectories
- **R-DDD-004** MUST: Controllers MUST be thin and limited to request validation, service invocation, and response formatting
- **R-DDD-005** MUST: Business logic MUST NOT be implemented directly in controller methods
- **R-DDD-006** SHOULD: Use dependency injection to provide services to controllers, avoiding direct instantiation
- **R-DDD-007** SHOULD: Define clear interfaces for cross-domain communication to avoid tight coupling between services

### Verify

```bash
# Count service classes in domain structure
find app/Domains -type f -name '*.php' -path '*/Services/*' | wc -l

# Verify service namespace compliance
grep -r 'namespace.*Domains.*Services' app/Domains --include='*.php' | wc -l

# Count controllers in domain structure
find app/Domains -type f -name '*Controller.php' -path '*/Web/Controllers/*' | wc -l

# Verify no business logic in controllers (basic check for service calls)
grep -r 'class.*Controller' app/Domains --include='*.php' -A 20 | grep -E '(SELECT|INSERT|UPDATE|DELETE|business logic)' | wc -l
```

**Accept when:**
- Service classes exist in app/Domains/{Domain}/{Feature}/Services/ directories
- Controllers exist in app/Domains/{Domain}/{Feature}/Web/Controllers/ directories
- At least 3 domain service classes follow the established pattern
- Service classes use proper namespace declarations matching their directory structure
- Controllers delegate business logic to service classes via dependency injection

<enforcement>
Claude Code MUST verify all R-DDD rules are satisfied before accepting changes to PHP files in the app/Domains directory. Violations of R-DDD-001 through R-DDD-005 (MUST rules) are blocking. Violations of R-DDD-006 and R-DDD-007 (SHOULD rules) should be flagged for review.
</enforcement>
