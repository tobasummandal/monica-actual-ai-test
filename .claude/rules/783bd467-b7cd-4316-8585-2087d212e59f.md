<rule_activation id="783bd467-b7cd-4316-8585-2087d212e59f" title="Use Laravel Hash Facade for Password Credential Storage: Plain Text Passwords" applies_to="**/*.php">
These rules are ALWAYS ACTIVE for all files matching `**/*.php` that handle user authentication, password management, account creation, user invitations, and password updates.
</rule_activation>

### Rules

- **R-HASH-001** MUST_NOT: Plain-text passwords MUST NOT be stored in any persistent storage including databases, logs, or cache
- **R-HASH-002** MUST: Use `Hash::make($password)` when storing passwords in service classes like CreateAccount or AcceptInvitation
- **R-HASH-003** MUST: Use `Hash::check($plaintext, $hashedValue)` for password verification during authentication
- **R-HASH-004** SHOULD: Use `Hash::fake()` in tests to avoid expensive hashing operations and speed up test execution
- **R-HASH-005** SHOULD: Review `config/hashing.php` to ensure appropriate algorithm (bcrypt or argon2id) and work factor for security requirements
- **R-HASH-006** SHOULD: Consider implementing password rehashing on successful login to automatically upgrade legacy hashes when algorithm configuration changes

### Verify

```bash
# Verify Hash::make usage in authentication files
grep -r "Hash::make" app/ --include="*.php" | wc -l

# Verify no direct password_hash usage (framework usage only)
grep -r "password_hash" app/ --include="*.php" || echo "No direct password_hash usage found (good)"

# Verify no plain-text password assignments
grep -r "'password'.*=>.*\$" app/ --include="*.php" | grep -v "Hash::make" | grep -v "bcrypt" || echo "No plain-text password assignments found (good)"

# Verify hashing driver configuration
php artisan tinker --execute="echo config('hashing.driver');"
```

**Accept when:**
- All password storage operations use `Hash::make()` as verified by grep showing consistent usage across authentication files
- No direct `password_hash()` calls found in application code (framework usage only)
- Hash facade configuration is properly set in `config/hashing.php` with bcrypt or argon2id driver
- Test suite includes verification that passwords are hashed before database storage
- No plain-text password assignments detected in account creation, password reset, password update, or user invitation workflows

<enforcement>
Claude Code MUST verify all rules before accepting password storage implementations. Violations of R-HASH-001 and R-HASH-002 are critical security issues and MUST block code generation or modification. CI pipeline verification is mandatory.
</enforcement>
