<rule_activation id="a1e929a7-d349-45d9-a52a-ede8e2c421fe" title="Adopt Modular Architecture with Factory-Based Component Generation: Scheduled Tasks Defined" applies_to="**/*">
These rules are ALWAYS ACTIVE for all application modules, domain components, database factories, console commands, view helpers, and scheduled task definitions.
</rule_activation>

### Rules

- **R-MODULAR-001** MUST: Scheduled tasks MUST be defined in a centralized Schedule class that extends the framework's scheduling infrastructure.
- **R-MODULAR-002** MUST: All PHP files in app/Domains directory MUST use the correct App\Domains namespace hierarchy.
- **R-MODULAR-003** MUST: All factory classes in database/factories MUST extend the framework's base Factory class.
- **R-MODULAR-004** MUST: All setup commands in app/Console/Commands MUST extend the framework's Command class and follow naming conventions.
- **R-MODULAR-005** SHOULD: Domain names should be singular nouns (Contact, not Contacts).
- **R-MODULAR-006** SHOULD: Subdomain names should describe the capability (ManageContact).
- **R-MODULAR-007** SHOULD: Layer names should be standard (Web, Console, Database).
- **R-MODULAR-008** SHOULD: Factory classes should be updated when domain models evolve to prevent test failures or incorrect seed data.
- **R-MODULAR-009** MAY: Simplified approach may be used for simple CRUD modules instead of full modular structure, with Architecture Review Board approval.

### Verify

```bash
# Verify all PHP files in app/Domains use correct namespace
find app/Domains -type f -name '*.php' | xargs grep -L 'namespace App\\Domains' | wc -l | grep -q '^0$'

# Verify all factory classes extend base Factory class
find database/factories -type f -name '*Factory.php' | xargs grep -c 'extends Factory' | grep -v ':0'

# Verify all setup commands extend Command class
find app/Console/Commands -type f -name 'Setup*.php' | xargs grep -c 'extends Command' | grep -v ':0'
```

**Accept when:**
- All PHP files in app/Domains directory use the correct App\Domains namespace hierarchy
- All factory classes in database/factories extend the framework's base Factory class
- All setup commands in app/Console/Commands extend the framework's Command class and follow naming conventions
- Scheduled tasks are defined in a centralized Schedule class extending framework scheduling infrastructure
- Module dependencies are documented in a central registry or dependency graph
- Code review checklist verifies module structure compliance

<enforcement>
Claude Code MUST NOT skip or defer verification. CI pipeline checks using PHPStan or Psalm MUST verify namespace conventions. Code review approval is withheld until module structure compliance is achieved. Violations block merge and require remediation.
</enforcement>
