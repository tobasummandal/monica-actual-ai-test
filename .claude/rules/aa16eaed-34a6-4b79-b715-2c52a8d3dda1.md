<rule_activation id="aa16eaed-34a6-4b79-b715-2c52a8d3dda" title="Adopt Domain-Driven Test Organization with Mirrored Directory Structure: Tests Organized Architectural" applies_to="tests/**/*Test.php">
These rules are ALWAYS ACTIVE for all test files matching `tests/**/*Test.php`. Tests MUST be organized by architectural layer (Services, Controllers, ViewHelpers) within each domain to support layer-specific test execution and maintain domain-driven design boundaries.
</rule_activation>

### Rules

- **R-DDT-001** SHOULD: Tests SHOULD be organized by architectural layer (Services, Controllers, ViewHelpers) within each domain to support layer-specific test execution.
- **R-DDT-002** MUST: All test files under `tests/Unit/Domains/` MUST have corresponding production files in `src/Domains/` with matching directory paths.
- **R-DDT-003** MUST: Test file namespaces MUST match the directory structure and mirror production code namespaces with `Tests\Unit` prefix.
- **R-DDT-004** SHOULD: Tests SHOULD respect domain boundaries and be organized to enable independent execution per domain.
- **R-DDT-005** MAY: Shared test utilities or abstract test base classes MAY be placed in a separate shared location (EX-001).
- **R-DDT-006** MAY: Legacy code being gradually migrated to domain-driven structure MAY use alternative organization temporarily (EX-002).

### Verify

```bash
# Check for orphaned tests without corresponding production files
find tests/Unit/Domains -name '*Test.php' | while read test; do
  src=$(echo $test | sed 's|tests/Unit/||' | sed 's|Test.php|.php|')
  [ -f "src/$src" ] || echo "Orphaned test: $test"
done

# Verify test namespaces match directory structure
grep -r 'namespace.*Tests\\Unit\\Domains' tests/Unit/Domains --include='*.php' | awk -F: '{print $1}' | while read f; do
  ns=$(grep namespace $f | head -1 | sed 's/.*namespace //;s/;//')
  path=$(echo $ns | sed 's/\\/\//g' | sed 's/Tests\\/Unit\\///')
  expected="tests/Unit/$path"
  actual=$(dirname $f)
  [ "$expected" = "$actual" ] || echo "Mismatch: $f"
done

# Verify all tests follow mirrored structure
phpunit --list-tests-xml | xmllint --xpath '//testCaseClass/@file' - | grep -v 'tests/Unit/Domains/.*/.*Test.php' && echo 'Non-conforming test locations found' || echo 'All tests follow mirrored structure'
```

**Accept when:**
- All test files under `tests/Unit/Domains/` have corresponding production files in `src/Domains/` with matching directory paths
- Test file namespaces match the directory structure and mirror production code namespaces with `Tests\Unit` prefix
- CI pipeline successfully executes domain-specific test suites using directory-based filtering
- No orphaned test files exist without corresponding production code
- No production classes lack corresponding test files in the mirrored location
- All tests are organized by architectural layer (Services, Controllers, ViewHelpers) within their respective domains

Claude Code MUST NOT skip or defer verification. All test files MUST conform to the mirrored directory structure. CI pipeline MUST fail if test files are found in non-conforming locations. Pull requests MUST be blocked until test organization issues are resolved.
