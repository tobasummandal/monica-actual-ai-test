<rule_activation id="a62f0b80-bf68-497a-917f-a441072b1f9f" title="Adopt Modular Architecture with Factory-Based Component Generation: View Helpers Isolated" applies_to="**/*.php">
These rules are ALWAYS ACTIVE for all PHP files in the application domains, factories, and console commands.
</rule_activation>

### Rules

- **R-MOD-001** SHOULD: View helpers SHOULD be isolated in dedicated ViewHelper classes within the Web layer of their respective domains.
- **R-MOD-002** SHOULD: Use domain-driven module organization with clear layer separation (Web, Console, Database).
- **R-MOD-003** SHOULD: Implement factory-based component generation for test data and seeding across database factories.
- **R-MOD-004** SHOULD: Organize console commands for setup, initialization, and maintenance with consistent naming conventions.
- **R-MOD-005** SHOULD: Use singular nouns for domain names (Contact, not Contacts) and descriptive names for subdomains (ManageContact).
- **R-MOD-006** SHOULD: Ensure all PHP files in app/Domains use the correct App\Domains namespace hierarchy.
- **R-MOD-007** SHOULD: Extend framework base Factory class for all factory classes in database/factories.
- **R-MOD-008** SHOULD: Extend framework Command class for all setup commands in app/Console/Commands.

### Verify

```bash
# Verify all PHP files in app/Domains use correct namespace
find app/Domains -type f -name '*.php' | xargs grep -L 'namespace App\\Domains' | wc -l | grep -q '^0$'

# Verify all factory classes extend base Factory class
find database/factories -type f -name '*Factory.php' | xargs grep -c 'extends Factory' | grep -v ':0'

# Verify all setup commands extend Command class
find app/Console/Commands -type f -name 'Setup*.php' | xargs grep -c 'extends Command' | grep -v ':0'
```

**Accept when:**
- All PHP files in app/Domains directory use the correct App\Domains namespace hierarchy
- All factory classes in database/factories extend the framework's base Factory class
- All setup commands in app/Console/Commands extend the framework's Command class and follow naming conventions
- View helpers are located in Web layer subdirectories of their respective domains
- Domain boundaries are clearly defined with no circular dependencies
- Module checklist items verified: correct namespace, factory present if needed, setup command if initialization required, view helpers in Web layer

<enforcement>
Claude Code MUST verify namespace conventions, factory inheritance, and command structure compliance before accepting code changes. CI pipeline checks using PHPStan or Psalm MUST pass. Code review checklist MUST confirm module structure compliance. Violations block merge and require remediation.
</enforcement>
