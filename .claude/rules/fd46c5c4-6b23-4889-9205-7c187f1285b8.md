<rule_activation id="fd46c5c4-6b23-4889-9205-7c187f1285b8" title="Standardize PHPUnit Test Structure with setUp and Trait-Based Helpers: Test Classes Extend" applies_to="tests/Unit/**/*Test.php">
These rules are ALWAYS ACTIVE for all PHPUnit unit test files in the tests/Unit/ directory.
</rule_activation>

### Rules

- **R-PHPUNIT-001** MUST: Test classes MUST extend PHPUnit\Framework\TestCase or an appropriate base test class

### Verify

```bash
# Find test files without setUp method
find tests/Unit -name '*Test.php' -type f | xargs grep -L 'function setUp' | wc -l

# Find test classes not extending PHPUnit\Framework\TestCase
grep -r 'class.*Test extends' tests/Unit/ | grep -v 'PHPUnit\\Framework\\TestCase' | wc -l

# Find non-test PHP files in tests/Unit
find tests/Unit -type f -name '*.php' ! -name '*Test.php' | wc -l
```

**Accept when:**
- All test files in tests/Unit/ contain a setUp() method or explicitly document why it's not needed
- All test classes extend PHPUnit\Framework\TestCase or a documented base test class
- Test file names match the pattern {ClassName}Test.php and are organized in directories mirroring the application structure

<enforcement>
Claude Code MUST verify all three bash commands pass before accepting changes to PHPUnit test files. Violations block merge in CI pipeline.
</enforcement>
