<rule_activation id="fd46c5c4-6b23-4889-9205-7c187f1285b8" title="Standardize PHPUnit Test Structure with setUp and Trait-Based Helpers: Test Classes Extend" applies_to="tests/Unit/**/*.php">
These rules are ALWAYS ACTIVE for all files matching `tests/Unit/**/*.php`.
</rule_activation>

### Rules

- **R-PHPUNIT-001** MUST: Test classes MUST extend PHPUnit\Framework\TestCase or an appropriate base test class
- **R-PHPUNIT-002** MUST: Test files MUST contain a setUp() method or explicitly document why it's not needed
- **R-PHPUNIT-003** MUST: Test file names MUST match the pattern {ClassName}Test.php and be organized in directories mirroring the application structure

### Verify

```bash
# Count test files missing setUp() methods (should be 0)
find tests/Unit -name '*Test.php' -type f | xargs grep -L 'function setUp' | wc -l

# Count test classes not extending PHPUnit\Framework\TestCase (should be 0)
grep -r 'class.*Test extends' tests/Unit/ | grep -v 'PHPUnit\\Framework\\TestCase' | wc -l

# Count PHP files in tests/Unit that don't match *Test.php pattern (should be 0)
find tests/Unit -type f -name '*.php' ! -name '*Test.php' | wc -l
```

**Accept when:**
- All test files in tests/Unit/ contain a setUp() method or explicitly document why it's not needed
- All test classes extend PHPUnit\Framework\TestCase or a documented base test class
- Test file names match the pattern {ClassName}Test.php and are organized in directories mirroring the application structure
