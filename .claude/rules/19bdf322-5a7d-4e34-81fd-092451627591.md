<rule_activation id="19bdf322-5a7d-4e34-81fd-092451627591" title="Standardize External API Integration with DAV Protocol and DTO Pattern: Permission Validation External" applies_to="**/*">
These rules are ALWAYS ACTIVE for all external API integrations including DAV, CardDAV, and CalDAV protocols, data transfer between external systems and internal domain models, resource import/export operations, permission validation for public-facing API endpoints, and backend interface implementations.
</rule_activation>

### Rules

- **R-DAV-001** MUST: Permission validation for external API operations MUST throw specific permission exceptions (NotEnoughPermissionException) rather than generic authorization errors.

### Verify

```bash
# Count DTO classes in external API integration paths
grep -r "class.*Dto" app/Domains/*/DavClient/Services/Utils/Model/ | wc -l

# Count backend interface definitions
grep -r "interface.*Backend" app/Domains/*/Dav/Web/Backend/ | wc -l

# Count domain-specific exception types for API failures
grep -r "class.*Exception extends" app/Domains/ | grep -E "(Permission|Compliant|Maximum)" | wc -l

# Count ViewHelper classes for API response preparation
find app/Domains -name "*ViewHelper.php" -type f | wc -l
```

**Accept when:**
- All external API integrations use DTO classes for data transfer with at least one DTO per external entity type
- Protocol-specific operations are abstracted behind interface contracts with at least one concrete implementation
- Domain-specific exception types exist for common API failure scenarios (permission, compliance, limits) and are properly caught in controllers
- ViewHelper classes are present for domains that expose external APIs and are used in controller response preparation
- Permission validation throws NotEnoughPermissionException specifically, not generic authorization errors

<enforcement>
Claude Code MUST NOT skip or defer verification. All external API integrations MUST comply with R-DAV-001 permission validation requirements. Violations require immediate remediation before deployment.
</enforcement>
