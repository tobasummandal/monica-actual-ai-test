<rule_activation id="924258c8-2bac-4eec-bc77-cd0919b2e012" title="Adopt Domain-Driven Controller Organization for Journal Management: Controllers Handling Journal" applies_to="app/Domains/Vault/ManageJournals/**/*.php">
These rules are ALWAYS ACTIVE for all files matching `app/Domains/Vault/ManageJournals/**/*.php`.

This rule enforces domain-driven controller organization for journal management features within the Vault domain. Controllers must be organized under the ManageJournals bounded context with clear separation of concerns by entity type.
</rule_activation>

### Rules

- **R-DDD-001** MUST: Controllers handling journal management features MUST be organized under the `app/Domains/Vault/ManageJournals/Web/Controllers` namespace.
- **R-DDD-002** MUST: Controller namespaces MUST match their directory structure and follow the established pattern.
- **R-DDD-003** MUST: Each controller MUST have a single, clear responsibility corresponding to an entity or entity-concern combination.
- **R-DDD-004** MUST: Route definitions MUST correctly reference controllers using the domain-based namespace.

### In Scope

- All web controllers within the Vault domain
- Controllers handling journal, post, photo, metric, and slice of life entities
- New controllers added to the ManageJournals bounded context
- API and web interface controllers for journal management

### Out of Scope

- Service classes and business logic layers
- Data transfer objects and view models
- Repository implementations
- Console commands and CLI controllers
- Background job handlers

### Exceptions

- **EX-001**: A controller handles cross-domain concerns that cannot be reasonably placed within a single domain boundary
- **EX-002**: Legacy controllers exist outside this structure and refactoring would introduce significant risk

### Verify

```bash
# Count controller files in the correct location
find app/Domains/Vault/ManageJournals/Web/Controllers -name '*Controller.php' 2>/dev/null | wc -l

# Verify controller namespaces match the pattern
grep -r 'namespace App\\Domains\\Vault\\ManageJournals\\Web\\Controllers' app/Domains/Vault/ManageJournals/Web/Controllers/*.php 2>/dev/null | wc -l

# Check route definitions reference correct controller namespace
php artisan route:list --path=journal --columns=Action 2>/dev/null | grep 'App\\Domains\\Vault\\ManageJournals\\Web\\Controllers'
```

**Accept when:**

- All controller files in the ManageJournals domain are located under `app/Domains/Vault/ManageJournals/Web/Controllers`
- Each controller has a single, clear responsibility corresponding to an entity or entity-concern combination
- Controller namespaces match their directory structure and follow the established pattern
- Route definitions correctly reference controllers using the domain-based namespace

<enforcement>
Claude Code MUST verify controller organization compliance before creating or modifying controllers in the journal management domain. Verification MUST NOT be skipped or deferred.
</enforcement>
