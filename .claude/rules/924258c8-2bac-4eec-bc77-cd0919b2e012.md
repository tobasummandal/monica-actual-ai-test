### Rules

- **R-JOURNAL-001** MUST: Controllers handling journal management features MUST be organized under the `app/Domains/Vault/ManageJournals/Web/Controllers` namespace.
- **R-JOURNAL-002** MUST: Each controller MUST have a single, clear responsibility corresponding to an entity or entity-concern combination (journals, posts, photos, metrics, slices of life).
- **R-JOURNAL-003** MUST: Controller namespaces MUST match their directory structure and follow the established domain-driven pattern.
- **R-JOURNAL-004** SHOULD: Use Laravel's route grouping to organize routes by domain with the correct namespace.
- **R-JOURNAL-005** SHOULD: Create a base controller class at `app/Domains/Vault/ManageJournals/Web/Controllers/Controller.php` to share common functionality.
- **R-JOURNAL-006** MAY: Use PHP traits for cross-cutting concerns like authorization, validation, and response formatting to avoid duplication across controllers.
