<rule_activation id="35680f9b-d01d-4d5e-a70b-a9f5be67e0b0" title="Adopt Mock-Based Unit Testing for External Service Dependencies in CI/CD Pipeline: Test Doubles Created" applies_to="**/*Test.php">
These rules are ALWAYS ACTIVE for all unit test files in the codebase. Mock-based testing is mandatory for external service dependencies to ensure fast, reliable, and deterministic CI/CD pipeline execution.
</rule_activation>

### Rules

- **R-MOCK-001** SHOULD: Test doubles SHOULD be created using the testing framework's built-in mocking capabilities (e.g., PHPUnit mocks, Mockery) for consistency.

### Verify

```bash
# Check for unmocked external service calls in unit tests
grep -r "new.*Client\|->connect\|->request" tests/Unit/ | grep -v "Mock\|Stub\|Fake" | wc -l

# Verify mocking patterns are in use
find tests/Unit -name '*Test.php' -exec grep -l 'createMock\|getMockBuilder\|shouldReceive' {} \; | wc -l

# Ensure no network-dependent tests in unit suite
phpunit --testsuite=unit --no-coverage --testdox | grep -i 'network\|connection\|timeout' || echo 'No network-dependent tests found'
```

**Accept when:**
- Unit tests execute successfully without network connectivity (verified by running tests with network disabled)
- Unit test suite completes in under 30 seconds for typical project size, indicating no real external service calls
- Grep verification shows that unit tests use mock/stub/fake patterns for external service dependencies
- CI/CD pipeline unit test stage has >95% success rate over 30-day period, indicating stable, non-flaky tests

<enforcement>
Claude Code MUST NOT skip or defer verification. All unit tests for external service dependencies MUST use mocking patterns. Code review MUST block merges if unit tests contain direct external service calls without documented exception approval. CI/CD pipeline MUST fail if unit tests exceed execution time threshold (30 seconds), indicating potential real service calls.
</enforcement>
