These rules are ALWAYS ACTIVE for all files matching the domain-driven service layer architecture pattern.
</rule_activation>

### Rules

- **R-DDD-001** MAY: Domain services MAY be reused across multiple controllers or other services when appropriate.

### Verify

```bash
# Count domain service files
find app/Domains -type f -name '*.php' -path '*/Services/*' | wc -l

# Verify service namespace compliance
grep -r 'namespace.*Domains.*Services' app/Domains --include='*.php' | wc -l

# Count domain controller files
find app/Domains -type f -name '*Controller.php' -path '*/Web/Controllers/*' | wc -l
```

**Accept when:**
- Service classes exist in `app/Domains/{Domain}/{Feature}/Services/` directories
- Controllers exist in `app/Domains/{Domain}/{Feature}/Web/Controllers/` directories
- At least 3 domain service classes follow the established pattern
- Business logic is isolated in service classes, not in controllers
- Proper namespace structure matches `Domains\{Domain}\{Feature}\Services`

<enforcement>
Claude Code MUST verify directory structure and namespace compliance before accepting code changes. Violations must be flagged and require architecture review approval.
</enforcement>
