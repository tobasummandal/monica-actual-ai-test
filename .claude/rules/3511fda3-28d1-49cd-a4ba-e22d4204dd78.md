<rule_activation id="3511fda3-28d1-49cd-a4ba-e22d4204dd78" title="Adopt PHP as Primary Backend Language for Laravel-Based Web Applications: Php Extensions Required" applies_to="**/*">
These rules are ALWAYS ACTIVE for all backend code and deployment configurations in Laravel-based web applications.
</rule_activation>

### Rules

- **R-PHP-001** MUST: PHP extensions required by Laravel (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) MUST be available in the deployment target.
- **R-PHP-002** MUST: All backend business logic and domain services MUST be written in PHP.
- **R-PHP-003** MUST: Authentication and authorization mechanisms (Fortify actions) MUST be implemented in PHP.
- **R-PHP-004** MUST: Web controllers and HTTP request handling MUST be implemented in PHP.
- **R-PHP-005** MUST: Database migrations and ORM operations MUST be implemented in PHP.
- **R-PHP-006** MUST: Feature and unit tests for backend functionality MUST be written in PHP.
- **R-PHP-007** MUST: API endpoints and web routes MUST be implemented in PHP.
- **R-PHP-008** MUST: Minimum PHP version 8.0+ MUST be specified in composer.json platform requirements.
- **R-PHP-009** SHOULD: Use Laravel Sail or Docker Compose for local development to ensure environment parity with production.
- **R-PHP-010** SHOULD: Implement automated testing in CI/CD that runs against the target PHP version.

### Verify

```bash
# Verify PHP version compatibility (8.0 or higher)
php --version | grep -E 'PHP [8-9]\.' && echo 'PHP version compatible' || echo 'PHP version incompatible'

# Verify required Laravel PHP extensions are present
php -m | grep -E '(openssl|pdo|mbstring|tokenizer|xml|ctype|json|bcmath)' | wc -l | grep -E '[8-9]|[1-9][0-9]' && echo 'Required extensions present' || echo 'Missing extensions'

# Verify PHP files exist in app directory
find app/ -name '*.php' -type f | wc -l | grep -E '[1-9][0-9]*' && echo 'PHP files detected in app directory' || echo 'No PHP files found'
```

**Accept when:**
- PHP version check returns 8.0 or higher in all deployment environments
- All required Laravel PHP extensions (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) are installed and enabled
- Application backend code in app/ directory consists primarily of PHP files with .php extension
- Composer dependencies successfully install and application bootstraps without runtime errors

<enforcement>
Claude Code MUST verify PHP version compatibility and required extension availability before approving any backend code changes or deployment configurations. Verification is mandatory and MUST NOT be skipped or deferred.
</enforcement>
