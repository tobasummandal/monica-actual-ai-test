<rule_activation id="80fd3d94-cbdd-4496-a2ff-0c39ccc71654" title="Adopt Mock-Based Unit Testing for External Service Dependencies in CI/CD Pipeline: Teams Use Contract" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files matching `**/*`. Unit tests for external service dependencies MUST use mock-based testing to ensure fast, reliable, and deterministic execution in CI/CD pipelines.
</rule_activation>

### Rules

- **R-MOCK-001** MAY: Teams MAY use contract testing or recorded fixtures to validate mock behavior against real service responses.

### Verify

```bash
# Verify unit tests do not contain direct external service calls
grep -r "new.*Client\|->connect\|->request" tests/Unit/ | grep -v "Mock\|Stub\|Fake" | wc -l

# Verify unit tests use mocking patterns
find tests/Unit -name '*Test.php' -exec grep -l 'createMock\|getMockBuilder\|shouldReceive' {} \; | wc -l

# Verify no network-dependent tests in unit suite
phpunit --testsuite=unit --no-coverage --testdox | grep -i 'network\|connection\|timeout' || echo 'No network-dependent tests found'
```

**Accept when:**
- Unit tests execute successfully without network connectivity (verified by running tests with network disabled)
- Unit test suite completes in under 30 seconds for typical project size, indicating no real external service calls
- Grep verification shows that unit tests use mock/stub/fake patterns for external service dependencies
- CI/CD pipeline unit test stage has >95% success rate over 30-day period, indicating stable, non-flaky tests

<enforcement>
Claude Code MUST verify that unit tests use mock-based testing for external service dependencies. Violations include direct HTTP client instantiation, real service calls, or network-dependent test execution. Code review MUST block merges that violate mocking standards without documented exception approval from tech leads. CI/CD pipeline MUST fail if unit tests exceed 30-second execution threshold or require network access.
</enforcement>
