<rule_activation id="2007ea0f-2e2e-450d-bc23-75b1cf2c1c31" title="Adopt Eloquent ORM Models as Standard Data Access Layer: Model Classes Placed" applies_to="**/*.php">
These rules are ALWAYS ACTIVE for all database-backed entities in the application. All data access operations MUST use Eloquent ORM models as the primary abstraction layer.
</rule_activation>

### Rules

- **R-ELOQUENT-001** MUST: Model classes MUST be placed in the app/Models namespace following Laravel's standard directory structure.
- **R-ELOQUENT-002** MUST: All persistent domain entities stored in relational database tables MUST use Eloquent ORM models for CRUD operations.
- **R-ELOQUENT-003** MUST: Define $fillable or $guarded properties immediately after model creation to prevent mass assignment vulnerabilities.
- **R-ELOQUENT-004** SHOULD: Document relationship methods with PHPDoc annotations specifying return types for better IDE support and static analysis.
- **R-ELOQUENT-005** SHOULD: Use model events (creating, created, updating, updated) for cross-cutting concerns like logging and auditing rather than duplicating logic in controllers.
- **R-ELOQUENT-006** SHOULD: Leverage Laravel's attribute casting ($casts property) to automatically convert database values to appropriate PHP types (dates, JSON, booleans).
- **R-ELOQUENT-007** SHOULD: Use model factories for testing to generate realistic test data without manual array construction.
- **R-ELOQUENT-008** MAY: Use raw SQL optimization for performance-critical queries that cannot be achieved through Eloquent query builder (EXC-001).
- **R-ELOQUENT-009** MAY: Use raw SQL for legacy database schemas with complex naming conventions incompatible with Eloquent conventions (EXC-002).

### Verify

```bash
# Count model files extending Eloquent Model
grep -r 'extends Model' app/Models/ | wc -l

# Find model files not in App\Models namespace
find app/Models -type f -name '*.php' | xargs grep -L 'namespace App\\Models'

# Display all models with table information
php artisan model:show --all | grep -E '(Table|Database)'

# Detect direct DB facade calls for CRUD operations (excluding approved exceptions)
grep -r 'DB::select\|DB::insert\|DB::update\|DB::delete' app/Http/Controllers/ app/Services/ | grep -v 'raw query approved'
```

**Accept when:**
- All model files exist in app/Models namespace and extend Illuminate\Database\Eloquent\Model
- No direct DB facade calls for CRUD operations found in controllers or services (excluding approved exceptions)
- Model count matches database table count for domain entities (excluding pivot tables and migrations table)
- All models define either $fillable or $guarded properties for mass assignment protection
- Relationship definitions are properly declared in model classes
- No N+1 query patterns detected in application layer
