<rule_activation id="7a44f2b4-bdbd-4669-aaca-a7ef48079ea0" title="Adopt HTTP Client Libraries for External API Integration: Vcard Vcalendar Data" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files integrating with external APIs, OAuth providers, WebDAV/CalDAV servers, and vCard/vCalendar data processing.
</rule_activation>

### Rules

- **R-HTTP-001** MUST: vCard and vCalendar data processing MUST use specialized parsing libraries (e.g., Sabre VObject) rather than custom string manipulation.
- **R-HTTP-002** MUST: All outbound HTTP/HTTPS requests to external APIs and services MUST use established HTTP client libraries (e.g., Guzzle, Socialite, Sabre DAV).
- **R-HTTP-003** MUST: OAuth provider integrations MUST use specialized libraries (e.g., Socialite) rather than custom OAuth implementations.
- **R-HTTP-004** MUST: WebDAV, CalDAV, and CardDAV protocol communications MUST use specialized protocol libraries (e.g., Sabre DAV).
- **R-HTTP-005** SHOULD: Wrap HTTP client library usage in service classes to encapsulate external API logic and provide domain-specific interfaces.
- **R-HTTP-006** SHOULD: Configure HTTP clients with appropriate timeouts, retry policies, and error handling strategies based on external service reliability requirements.
- **R-HTTP-007** SHOULD: Use dependency injection to provide HTTP client instances for testability and configuration flexibility.
- **R-HTTP-008** SHOULD: Document authentication patterns for each integration type (OAuth, Basic Auth, API keys) with code examples.
- **R-HTTP-009** SHOULD: Implement logging and monitoring for external API calls to track performance, errors, and usage patterns.

### Verify

```bash
# Verify Socialite usage in OAuth flows
grep -r "use.*Socialite" app/ --include="*.php" | wc -l

# Verify Sabre DAV/VObject usage for protocols and data formats
grep -r "use.*Sabre" app/ --include="*.php" | wc -l

# Verify no raw cURL or socket implementations in new code
grep -r "curl_exec\|fsockopen" app/ --include="*.php" | wc -l
```

**Accept when:**
- Socialite library usage is detected in OAuth authentication flows
- Sabre DAV/VObject libraries are used for DAV protocol and vCard/vCalendar operations
- No raw cURL or socket implementations (curl_exec, fsockopen) are found in new external API integration code
- Service classes encapsulate HTTP client library usage with clear domain interfaces
- HTTP clients are configured with timeouts, retry policies, and error handling
- Dependency injection is used for HTTP client provisioning
- External API calls include logging and monitoring instrumentation

<enforcement>
Claude Code MUST verify compliance with R-HTTP-001 through R-HTTP-009 before accepting external API integration code. Automated checks MUST scan for raw HTTP implementations. Manual review MUST confirm service class encapsulation and library usage patterns. Violations without documented exceptions MUST be flagged for revision.
</enforcement>
