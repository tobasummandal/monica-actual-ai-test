<rule_activation id="77ef8512-04f4-489d-b7f1-68e980f4278a" title="Adopt PHP as Primary Backend Language for Laravel-Based Web Applications: Authentication Security Critical" applies_to="**/*">
These rules are ALWAYS ACTIVE for all files in the Laravel-based web application codebase.
</rule_activation>

### Rules

- **R-PHP-001** MUST: Authentication and security-critical operations (password reset, user management) MUST execute within the PHP runtime using Laravel's built-in security features.
- **R-PHP-002** MUST: All backend business logic and domain services MUST be implemented in PHP.
- **R-PHP-003** MUST: Web controllers and HTTP request handling MUST be implemented in PHP using Laravel conventions.
- **R-PHP-004** MUST: Database migrations and ORM operations MUST use PHP with Laravel's Eloquent or database query builder.
- **R-PHP-005** MUST: Feature and unit tests for backend functionality MUST be written in PHP using PHPUnit.
- **R-PHP-006** MUST: API endpoints and web routes MUST be defined and handled in PHP.
- **R-PHP-007** MUST: Minimum PHP version 8.0+ MUST be specified in composer.json platform requirements.
- **R-PHP-008** MUST: Required Laravel PHP extensions (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) MUST be available in all deployment environments.
- **R-PHP-009** SHOULD: Backend code SHOULD follow Laravel framework conventions and patterns (Actions, Controllers, Services, domain-driven design).
- **R-PHP-010** SHOULD: Use Laravel Sail or Docker Compose for local development to ensure environment parity with production.

### Out of Scope

- Frontend JavaScript/TypeScript code executed in browser
- Build tools and asset compilation (npm, webpack, vite)
- Infrastructure-as-code scripts (Terraform, Ansible)
- CI/CD pipeline scripts (bash, yaml configurations)
- Database stored procedures or functions written in SQL dialects

### Verify

```bash
# Check PHP version compatibility
php --version | grep -E 'PHP [8-9]\.' && echo 'PHP version compatible' || echo 'PHP version incompatible'

# Verify required PHP extensions are installed
php -m | grep -E '(openssl|pdo|mbstring|tokenizer|xml|ctype|json|bcmath)' | wc -l | grep -E '[8-9]|[1-9][0-9]' && echo 'Required extensions present' || echo 'Missing extensions'

# Confirm PHP files exist in app directory
find app/ -name '*.php' -type f | wc -l | grep -E '[1-9][0-9]*' && echo 'PHP files detected in app directory' || echo 'No PHP files found'
```

**Accept when:**
- PHP version check returns 8.0 or higher in all deployment environments
- All required Laravel PHP extensions (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) are installed and enabled
- Application backend code in app/ directory consists primarily of PHP files with .php extension
- Composer dependencies successfully install and application bootstraps without runtime errors

<enforcement>
Claude Code MUST verify PHP runtime compatibility before deploying or modifying authentication and security-critical backend components. Verification MUST NOT be skipped or deferred. Code review process MUST ensure new backend code is written in PHP following Laravel conventions. Exceptions for non-PHP backend components require architectural review board approval with documented justification.
</enforcement>
