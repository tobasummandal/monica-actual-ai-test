<rule_activation id="93a0e5b9-e594-45b2-98eb-64946e4817ad" title="Adopt PHP as Primary Backend Language for Laravel-Based Web Applications: Deployment Environment Provide" applies_to="**/*">
These rules are ALWAYS ACTIVE for all backend code and deployment configurations in Laravel-based web applications.
</rule_activation>

### Rules

- **R-PHP-001** MUST: The deployment environment MUST provide PHP runtime version compatible with Laravel framework requirements (PHP 8.0 or higher recommended).
- **R-PHP-002** MUST: All backend business logic and domain services MUST be implemented in PHP.
- **R-PHP-003** MUST: Authentication and authorization mechanisms (Fortify actions) MUST be implemented in PHP.
- **R-PHP-004** MUST: Web controllers and HTTP request handling MUST be implemented in PHP.
- **R-PHP-005** MUST: Database migrations and ORM operations MUST be implemented in PHP.
- **R-PHP-006** MUST: Feature and unit tests for backend functionality MUST be implemented in PHP.
- **R-PHP-007** MUST: API endpoints and web routes MUST be implemented in PHP.
- **R-PHP-008** MUST: Specify minimum PHP version (8.0+) in composer.json platform requirements to prevent deployment on incompatible runtimes.
- **R-PHP-009** SHOULD: Use Laravel Sail or Docker Compose for local development to ensure environment parity with production deployment targets.
- **R-PHP-010** SHOULD: Document required PHP extensions and configuration (memory_limit, max_execution_time, upload_max_filesize) in deployment runbooks.
- **R-PHP-011** SHOULD: Implement automated testing in CI/CD that runs against the target PHP version to catch compatibility issues early.
- **R-PHP-012** SHOULD: Consider using PHP-FPM with nginx or Apache for production deployments to optimize process management and resource utilization.

### Verify

```bash
# Verify PHP version compatibility
php --version | grep -E 'PHP [8-9]\.' && echo 'PHP version compatible' || echo 'PHP version incompatible'

# Verify required Laravel PHP extensions are present
php -m | grep -E '(openssl|pdo|mbstring|tokenizer|xml|ctype|json|bcmath)' | wc -l | grep -E '[8-9]|[1-9][0-9]' && echo 'Required extensions present' || echo 'Missing extensions'

# Verify PHP files detected in app directory
find app/ -name '*.php' -type f | wc -l | grep -E '[1-9][0-9]*' && echo 'PHP files detected in app directory' || echo 'No PHP files found'
```

**Accept when:**
- PHP version check returns 8.0 or higher in all deployment environments
- All required Laravel PHP extensions (OpenSSL, PDO, Mbstring, Tokenizer, XML, Ctype, JSON, BCMath) are installed and enabled
- Application backend code in app/ directory consists primarily of PHP files with .php extension
- Composer dependencies successfully install and application bootstraps without runtime errors
- composer.json specifies minimum PHP version 8.0 or higher in platform requirements
- No non-PHP backend code exists without documented architectural review board approval
