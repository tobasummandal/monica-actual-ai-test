<rule_activation id="90f87fea-17ec-4c93-b385-6e9fadb6fee9" title="Standardize Logging with Laravel Log Facade in DAV and Job Components: Synchronization Services Use" applies_to="{app/Domains/Contact/Dav*/**/*.php,app/Console/Commands/**/*.php}">
These rules are ALWAYS ACTIVE for DAV backend implementations (CalDAV/CardDAV), background jobs in Contact/Dav and Contact/DavClient domains, DavClient service utilities and synchronization services, console commands for address book and application setup, and any component performing external DAV server communication.
</rule_activation>

### Rules

- **R-LOG-001** MUST: Import Laravel's Log facade (`use Illuminate\Support\Facades\Log;`) in all DAV backend classes, DavClient services, and relevant console commands.
- **R-LOG-002** MUST: Use Laravel's Log facade for all logging operations in synchronization services and background jobs (not direct Monolog usage or custom logging services).
- **R-LOG-003** SHOULD: Use appropriate log levels: `Log::debug()` for routine operations, `Log::info()` for significant events, `Log::warning()` for recoverable issues, `Log::error()` for failures.
- **R-LOG-004** SHOULD: Include structured context as second parameter: `Log::info('VCard synchronized', ['contact_id' => $id, 'addressbook_id' => $addressbookId])`.
- **R-LOG-005** MUST: Log at the beginning and end of job `handle()` methods with job-specific context to enable job execution tracking.
- **R-LOG-006** SHOULD: Consider using a dedicated channel for DAV operations configured in config/logging.php: `Log::channel('dav')->info('Sync started')`.
- **R-LOG-007** SHOULD: Avoid logging in tight loops; consider sampling or aggregating log messages for bulk operations.

### Verify

```bash
# Check for Log facade imports in DAV and console command files
grep -r "use Illuminate\\\\Support\\\\Facades\\\\Log" app/Domains/Contact/Dav* app/Console/Commands/ | wc -l

# Verify Log method calls with appropriate levels
grep -r "Log::" app/Domains/Contact/Dav* app/Console/Commands/ | grep -E "(debug|info|warning|error)" | wc -l

# Confirm Log facade is available in the application
php artisan tinker --execute="echo class_exists('Illuminate\\\\Support\\\\Facades\\\\Log') ? 'PASS' : 'FAIL';"
```

**Accept when:**
- Log facade import statements are present in all DAV backend classes, DavClient services, and relevant console commands
- Log method calls (debug/info/warning/error) are present in job handle() methods and synchronization service methods
- Laravel's Log facade class is available and properly configured in the application

<enforcement>
Claude Code MUST verify these rules when modifying DAV synchronization components, background jobs, or console commands. Verification MUST NOT be skipped or deferred.
</enforcement>
