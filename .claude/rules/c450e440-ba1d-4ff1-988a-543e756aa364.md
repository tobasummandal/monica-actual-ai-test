<rule_activation id="c450e440-ba1d-4ff1-988a-543e756aa364" title="Adopt CardDAV/WebDAV Protocol for External Contact Synchronization: Dav Client Services" applies_to="app/Domains/Contact/Dav*/**/*">
These rules are ACTIVE for all external contact synchronization integrations and DAV protocol implementations within the Contact domain.
</rule_activation>

### Rules

- **R-DAVCS-001** SHOULD: DAV client services SHOULD be organized under dedicated DavClient namespace to separate external integration concerns from core domain logic.
- **R-DAVCS-002** MUST: All DAV backend classes MUST implement the IDAVBackend interface.
- **R-DAVCS-003** MUST: All external API communication MUST use ContactDto and ContactDeleteDto models consistently.
- **R-DAVCS-004** MUST: DAV client services MUST implement comprehensive error handling using DavServerNotCompliantException for non-compliant servers.
- **R-DAVCS-005** SHOULD: Create separate resource handlers (ImportResource, ImportVCardResource) to handle different import scenarios following single responsibility principle.
- **R-DAVCS-006** SHOULD: Add integration tests that verify compatibility with major CardDAV implementations (Nextcloud, Radicale, Apple Calendar Server).

### Verify

```bash
# Verify IDAVBackend interface implementation
grep -r "IDAVBackend" app/Domains/Contact/Dav/ --include="*.php" | wc -l

# Verify ContactDto and ContactDeleteDto usage
grep -r "ContactDto\|ContactDeleteDto" app/Domains/Contact/DavClient/ --include="*.php" | wc -l

# Verify DavServerNotCompliantException presence
grep -r "DavServerNotCompliantException" app/Domains/Contact/ --include="*.php" | wc -l

# Verify Import resource handlers
find app/Domains/Contact/Dav* -name "*Import*Resource.php" -o -name "*VCard*.php" | wc -l
```

**Accept when:**
- All DAV backend implementations implement the IDAVBackend interface (verify command returns > 0)
- Contact DTO models are consistently used across DavClient services (verify command returns >= 2 for both DTOs)
- DavServerNotCompliantException is present and used for error handling (verify command returns > 0)
- Import resource handlers exist for DAV and vCard operations (verify command returns >= 2)
