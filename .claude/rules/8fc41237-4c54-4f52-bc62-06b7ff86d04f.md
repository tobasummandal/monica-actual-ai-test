<rule_activation id="8fc41237-4c54-4f52-bc62-06b7ff86d04f" title="Standardize PHPUnit Test Structure with setUp and Trait-Based Helpers: Test Classes Use" applies_to="tests/Unit/**/*.php">
These rules are ALWAYS ACTIVE for all files matching `tests/Unit/**/*.php`.
</rule_activation>

### Rules

- **R-PHPUNIT-001** SHOULD: Test classes SHOULD use trait-based helper utilities (e.g., DatabaseTransactions, RefreshDatabase) for shared testing functionality.
- **R-PHPUNIT-002** SHOULD: Test files SHOULD contain a setUp() method or explicitly document why it's not needed.
- **R-PHPUNIT-003** MUST: Test classes MUST extend PHPUnit\Framework\TestCase or a documented base test class.
- **R-PHPUNIT-004** MUST: Test file names MUST match the pattern {ClassName}Test.php and be organized in directories mirroring the application structure.

### Verify

```bash
# Count test files missing setUp() method
find tests/Unit -name '*Test.php' -type f | xargs grep -L 'function setUp' | wc -l

# Count test classes not extending PHPUnit\Framework\TestCase
grep -r 'class.*Test extends' tests/Unit/ | grep -v 'PHPUnit\\Framework\\TestCase' | wc -l

# Count non-test PHP files in Unit test directory
find tests/Unit -type f -name '*.php' ! -name '*Test.php' | wc -l
```

**Accept when:**
- All test files in tests/Unit/ contain a setUp() method or explicitly document why it's not needed
- All test classes extend PHPUnit\Framework\TestCase or a documented base test class
- Test file names match the pattern {ClassName}Test.php and are organized in directories mirroring the application structure
