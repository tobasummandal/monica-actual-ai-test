<rule_activation id="854ce89e-ba13-4f00-a4f3-13fdd4991899" title="Adopt Eloquent ORM Models as Standard Data Access Layer: Models Use Type" applies_to="**/*.php">
These rules are ALWAYS ACTIVE for all PHP files in the application, particularly those in app/Models and files performing database access.
</rule_activation>

### Rules

- **R-ELOQUENT-001** SHOULD: Models SHOULD use type casting via the `$casts` property for automatic attribute transformation.

### Verify

```bash
# Verify all models extend Eloquent Model
grep -r "extends Model" app/Models/ | wc -l

# Find models missing proper namespace
find app/Models -name '*.php' -exec grep -L 'namespace App\\Models' {} \;

# Count total model classes
php artisan model:show --all 2>&1 | grep -c 'class'

# Find direct database queries outside models (excluding documented exceptions)
grep -r "DB::table\|DB::select" app/Http app/Services | grep -v "// Exception" | wc -l
```

**Accept when:**
- All model files in `app/Models` extend `Illuminate\Database\Eloquent\Model`
- At least 7 model classes exist matching the detected pattern (File, PostTemplateSection, ContactInformationType, GiftOccasion, CallReasonType, Account, QuickFact)
- Models define either `$fillable` or `$guarded` properties for mass assignment protection
- Direct database queries outside models are documented with exception justifications (EXC-001, EXC-002)
- Models use type casting via `$casts` property for attribute transformation

<enforcement>
Claude Code MUST verify all acceptance criteria before approving model implementations. Verification is mandatory and cannot be deferred. Code review must confirm model namespace placement, inheritance, mass assignment protection, and type casting usage.
</enforcement>
