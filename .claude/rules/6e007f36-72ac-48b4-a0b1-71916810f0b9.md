<rule_activation id="6e007f36-72ac-48b4-a0b1-71916810f0b9" title="Adopt PHPUnit for Unit Testing in Domain-Driven Architecture: Test Class Files" applies_to="tests/Unit/Domains/**/*Test.php">
These rules are ALWAYS ACTIVE for all unit test files in domain-driven architecture following PHPUnit conventions.
</rule_activation>

### Rules

- **R-PHPUNIT-001** MUST: Test class files MUST follow the naming convention {ClassName}Test.php where {ClassName} is the class under test

### Verify

```bash
# Count test files following naming convention
find tests/Unit/Domains -name '*Test.php' -type f | wc -l

# Verify PHPUnit TestCase usage
grep -r 'use PHPUnit\\Framework\\TestCase' tests/Unit/Domains/ | wc -l

# Execute PHPUnit test suite
vendor/bin/phpunit --testsuite=unit --testdox
```

**Accept when:**
- All test files in tests/Unit/Domains/ follow the {ClassName}Test.php naming convention
- PHPUnit test execution completes successfully with all tests passing
- Test directory structure mirrors the application domain hierarchy under tests/Unit/Domains/
- Code coverage reports are generated during CI builds

<enforcement>
Claude Code MUST NOT skip or defer verification. All test files MUST adhere to the {ClassName}Test.php naming convention. CI/CD pipeline MUST execute PHPUnit tests on every commit and fail if tests do not pass or naming conventions are violated.
</enforcement>
