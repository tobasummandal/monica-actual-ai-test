<rule_activation id="5026b11c-c830-4d13-9ebc-1db849903edf" title="Adopt Eloquent ORM Models as Standard Data Access Layer: Database Entities Represented" applies_to="app/Models/**/*.php">
These rules are ALWAYS ACTIVE for all database entity representations in the Laravel application.
</rule_activation>

### Rules

- **R-ELQ-001** MUST: All database entities MUST be represented as Eloquent Model classes extending Illuminate\Database\Eloquent\Model
- **R-ELQ-002** MUST: All models in app/Models MUST define either $fillable or $guarded properties for mass assignment protection
- **R-ELQ-003** SHOULD: Define relationships using type-hinted return types (e.g., public function posts(): HasMany) for better IDE support and static analysis
- **R-ELQ-004** SHOULD: Use model factories for testing to ensure consistent test data generation across the test suite
- **R-ELQ-005** SHOULD: Document complex query scopes and custom accessors with PHPDoc blocks explaining their purpose and usage
- **R-ELQ-006** SHOULD: Consider using model observers for cross-cutting concerns like logging, caching, or event dispatching rather than cluttering model methods
- **R-ELQ-007** SHOULD: Enforce eager loading in code reviews to prevent N+1 query problems
- **R-ELQ-008** SHOULD: Refactor models exceeding 300 lines to maintain single responsibility principle
- **R-ELQ-009** MAY: Use raw SQL queries or Query Builder directly for legacy database schemas that cannot be efficiently expressed through Eloquent (EXC-001)
- **R-ELQ-010** MAY: Use Query Builder or raw SQL for read-only reporting queries spanning multiple complex joins (EXC-002)

### Verify

```bash
# Count models extending Eloquent
grep -r "extends Model" app/Models/ | wc -l

# Find models not in correct namespace
find app/Models -name '*.php' -exec grep -L 'namespace App\\Models' {} \;

# List all models
php artisan model:show --all 2>&1 | grep -c 'class'

# Find direct database queries outside models (excluding documented exceptions)
grep -r "DB::table\|DB::select" app/Http app/Services | grep -v "// Exception" | wc -l
```

**Accept when:**
- All model files in app/Models extend Illuminate\Database\Eloquent\Model
- At least 7 model classes exist matching the detected pattern (File, PostTemplateSection, ContactInformationType, GiftOccasion, CallReasonType, Account, QuickFact)
- Models define either $fillable or $guarded properties for mass assignment protection
- Direct database queries outside models are documented with exception justifications (EXC-001, EXC-002)
- Models are placed in app/Models namespace with proper naming conventions
- No models lack mass assignment protection definitions
