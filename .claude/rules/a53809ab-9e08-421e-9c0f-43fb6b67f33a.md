<rule_activation id="a53809ab-9e08-421e-9c0f-43fb6b67f33a" title="Standardize Eloquent Models as Primary Data Access Layer with Public API Contracts: Models Define Custom" applies_to="app/Models/**/*.php">
These rules are ALWAYS ACTIVE for all data modeling and database access patterns within the application codebase. All persistent domain entities requiring database storage MUST use Eloquent models as the primary data access layer.
</rule_activation>

### Rules

- **R-EDQ-001** MAY: Models MAY define custom query scopes to encapsulate common query patterns.
- **R-EDQ-002** MUST: All model classes in app/Models extend Illuminate\Database\Eloquent\Model.
- **R-EDQ-003** MUST: Document all public methods, relationships, and custom attributes in PHPDoc blocks to establish clear API contracts.
- **R-EDQ-004** SHOULD: Leverage Laravel's $casts property to ensure consistent type handling for attributes (dates, booleans, JSON).
- **R-EDQ-005** SHOULD: Use model events (creating, updating, etc.) for cross-cutting concerns like auditing rather than scattering logic across controllers.
- **R-EDQ-006** SHOULD: Use Laravel model factories for test data generation to ensure consistency between tests and production models.
- **R-EDQ-007** MUST: Raw database queries outside models require documented justification or exception approval.
- **R-EDQ-008** SHOULD: Establish clear boundaries: models handle data access and simple transformations, complex business logic belongs in service classes or domain objects.
- **R-EDQ-009** SHOULD: Treat model public methods as API contracts, use deprecation notices before removal, maintain comprehensive test coverage for model interfaces.
- **R-EDQ-010** SHOULD: Implement query monitoring and enforce eager loading in code reviews to prevent N+1 query problems.

### Verify

```bash
# Count model classes extending Eloquent Model
grep -r "class.*extends.*Model" app/Models/ | wc -l

# Check for syntax errors in model files
find app/Models -name '*.php' -exec php -l {} \; | grep -v 'No syntax errors'

# Count raw database queries outside models (should be minimal)
grep -r "DB::raw\|DB::select\|DB::statement" app/ --exclude-dir=Models | wc -l
```

**Accept when:**
- All model classes in app/Models extend Illuminate\Database\Eloquent\Model
- No syntax errors in model files and all models are loadable by PHP parser
- Raw database queries outside models are documented with justification or count is below threshold (e.g., <5 instances)
- All public model methods have PHPDoc documentation
- Query monitoring in staging environment detects no N+1 problems

<enforcement>
Claude Code MUST verify all rules before accepting changes to data access patterns. Violations of R-EDQ-002 and R-EDQ-007 MUST block code acceptance. Performance regression tests MUST pass. Architecture review is required for any data access patterns deviating from this standard.
</enforcement>
