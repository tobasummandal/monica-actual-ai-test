<rule_activation id="773ccd70-a291-4972-afc1-1ddc8186edfe" title="Adopt CardDAV/WebDAV Protocol for External Contact Synchronization: Non Compliant Dav" applies_to="**/*">
These rules are ALWAYS ACTIVE for all external contact synchronization integrations and DAV protocol implementations within the Contact domain.
</rule_activation>

### Rules

- **R-DAV-001** MUST: Non-compliant DAV servers MUST be handled with specific exceptions (DavServerNotCompliantException) to provide clear error diagnostics.

### Scope

**In scope:**
- All contact synchronization with external CardDAV/WebDAV servers
- vCard import and export operations for contact data
- DAV backend interface implementations
- Contact DTO models for external API communication
- Error handling for non-compliant DAV servers

**Out of scope:**
- Internal contact storage and database operations
- REST API endpoints for web/mobile clients
- GraphQL APIs for internal services
- Non-DAV third-party integrations (OAuth-based APIs, webhooks)
- Real-time synchronization protocols (WebSocket, Server-Sent Events)

**Exceptions:**
- EX-001: Legacy contact import from proprietary formats (CSV, Excel) that cannot be converted to vCard
- EX-002: Emergency fallback to direct database operations when DAV server is persistently unavailable

### Verify

```bash
# Verify IDAVBackend interface implementation
grep -r "IDAVBackend" app/Domains/Contact/Dav/ --include="*.php" | wc -l

# Verify ContactDto and ContactDeleteDto usage
grep -r "ContactDto\|ContactDeleteDto" app/Domains/Contact/DavClient/ --include="*.php" | wc -l

# Verify DavServerNotCompliantException presence and usage
grep -r "DavServerNotCompliantException" app/Domains/Contact/ --include="*.php" | wc -l

# Verify Import resource handlers exist
find app/Domains/Contact/Dav* -name "*Import*Resource.php" -o -name "*VCard*.php" | wc -l
```

**Accept when:**
- All DAV backend implementations implement the IDAVBackend interface (verify command 1 returns > 0)
- Contact DTO models are consistently used across DavClient services (verify command 2 returns >= 2 for both DTOs)
- DavServerNotCompliantException is present and used for error handling (verify command 3 returns > 0)
- Import resource handlers exist for DAV and vCard operations (verify command 4 returns >= 2)

<enforcement>
Claude Code MUST verify all conditions before accepting changes to DAV protocol implementations. Verification is mandatory and cannot be deferred. CI pipeline MUST fail if DAV backend classes do not implement IDAVBackend interface. Pull requests MUST be blocked if external API calls bypass DTO models. Architecture review MUST be triggered if new contact synchronization code is added outside the DavClient namespace. Warning notifications MUST be generated if DavServerNotCompliantException is not caught in DAV client service methods.
</enforcement>
